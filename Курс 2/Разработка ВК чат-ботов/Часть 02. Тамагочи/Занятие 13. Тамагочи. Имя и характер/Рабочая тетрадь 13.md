### Шаг 2. Добавляем безопасное переименование

**Где работаем:** Редактор pet_db.py: новая функция в конце.

Пользователь вводит текст, поэтому передаём его через ? отдельно от SQL. Не используйте f-строку для сборки запроса и INSERT OR REPLACE: здесь меняется только имя.

**Куда вставить:** В конец pet_db.py без внешнего отступа.

**Зачем и почему здесь:** Валидация у функции защищает БД даже при вызове из проверки, а WHERE не даёт переименовать всех питомцев.

```python
def rename_pet(conn, owner_id, name):
    name = name.strip()
    if not 2 <= len(name) <= 20:
        return False
    with conn:
        cur = conn.execute(
            "UPDATE pets SET name = ? WHERE owner_id = ?", (name, owner_id)
        )
    return cur.rowcount == 1
```

**Что наблюдать и как проверить:** Имя из двух слов или с апострофом допустимо. Пустая строка и длина больше 20 возвращают False и не меняют БД.

- [ ] Получилось; могу объяснить место и назначение правки.

### Шаг 3. Разбираем команду с аргументом

**Где работаем:** Редактор pet_bot.py: импорт и ветка до финального else.

Блок команды содержит проверку наличия питомца. Split с maxsplit=1 сохраняет имя из нескольких слов. Отдельное сообщение «Имя» показывает пример, а слово «имярек» не считается командой.

**Куда вставить:** К импортам pet_bot.py.

**Зачем и почему здесь:** Функция должна быть доступна до вызова в обработчике.

```python
from pet_db import rename_pet
```

**Куда вставить:** Перед последним else, отступ elif — 12 пробелов.

**Зачем и почему здесь:** Проверяем количество частей раньше parts[1]. Сохранение идёт только после проверки владельца.

```python
            elif user_text == "имя" or user_text.startswith("имя "):
                parts = raw_text.split(maxsplit=1)
                if get_pet(conn, user_id) is None:
                    reply = "Сначала напиши Приютить."
                elif len(parts) < 2:
                    reply = "Пример: Имя Луна"
                else:
                    changed = rename_pet(conn, user_id, parts[1])
                    reply = "Имя сохранено!" if changed else "Нужно от 2 до 20 символов."
```

**Что наблюдать и как проверить:** Перезапустите. «ИМЯ Луна» сохраняет Луна с заглавной буквы; «Имя Я» отказывается. После перезапуска имя прежнее; показатели не сброшены. Небольшое изменение от времени — работа урока 12, а не переименование.

- [ ] Получилось; могу объяснить место и назначение правки.

### Шаг 4. Показываем потребности

**Где работаем:** Редактор pet_bot.py: карточка питомца.

Внутри «питомец» после проверки None добавим вычисление статуса, затем дополним прежний reply. Статус вычисляется из показателей; хранить ещё один столбец не нужно.

**Куда вставить:** Внутри else ветки «питомец» перед присваиванием reply. Отступ status — 20 пробелов.

**Зачем и почему здесь:** К этому месту pet существует и уже пересчитан по времени, поэтому подсказка отражает актуальное состояние.

```python
                    status = "Питомец доволен!"
                    if pet["satiety"] < 30:
                        status = "Питомец проголодался. Нажми Кормить."
                    elif pet["energy"] < 30:
                        status = "Питомец устал. Нажми Отдыхать."
                    elif pet["mood"] < 30:
                        status = "Питомец скучает. Нажми Играть."
```

**Куда вставить:** После существующей многострочной сборки reply в том же else. Отступ — 20 пробелов.

**Зачем и почему здесь:** Дополнение идёт после основного текста, иначе следующее присваивание reply затёрло бы подсказку.

```python
                    reply += "\n" + status
```

**Что наблюдать и как проверить:** После перезапуска карточка содержит показатели и одно действие при недостатке. При нескольких потребностях сначала еда, потом отдых, затем игра: это порядок if/elif.
