### Шаг 2. Добавляем кормление

**Где работаем:** Редактор pet_db.py, после adopt_pet.

Каждая функция принимает соединение и владельца. With conn фиксирует успешный UPDATE и откатывает ошибочный, но не закрывает соединение: закрытие остаётся в finally бота.

**Куда вставить:** В конец pet_db.py без внешнего отступа.

**Зачем и почему здесь:** Одно условное UPDATE увеличивает показатель и ограничивает владельца. MIN не даёт превысить 100; rowcount различает изменение и отказ.

```python
def feed_pet(conn, owner_id):
    with conn:
        cur = conn.execute(
            "UPDATE pets SET satiety = MIN(100, satiety + 20) "
            "WHERE owner_id = ? AND satiety < 100", (owner_id,)
        )
    return cur.rowcount
```

**Что наблюдать и как проверить:** Сохраните. Пока бот не импортирует и не вызывает функцию, сама карточка не изменится. Проверка действия будет после сборки обработчика на шаге 4.

- [ ] Получилось; могу объяснить место и назначение правки.

### Шаг 3. Добавляем отдых и игру

**Где работаем:** Редактор pet_db.py после feed_pet.

Разместите две отдельные функции рядом с кормлением. У игры одно UPDATE на три поля: отказ не должен частично менять состояние.

**Куда вставить:** После feed_pet, без внешнего отступа.

**Зачем и почему здесь:** Отдых восстанавливает энергию существующего питомца; условие не позволяет сообщать об изменении при полном запасе.

```python
def rest_pet(conn, owner_id):
    with conn:
        cur = conn.execute(
            "UPDATE pets SET energy = MIN(100, energy + 25) "
            "WHERE owner_id = ? AND energy < 100", (owner_id,)
        )
    return cur.rowcount
```

**Куда вставить:** После rest_pet, без внешнего отступа.

**Зачем и почему здесь:** Три показателя меняются одновременно только при выполнении обоих условий. MAX для сытости здесь не нужен: WHERE уже проверил запас.

```python
def play_pet(conn, owner_id):
    with conn:
        cur = conn.execute(
            "UPDATE pets SET satiety = satiety - 10, energy = energy - 15, "
            "mood = MIN(100, mood + 15) "
            "WHERE owner_id = ? AND satiety >= 10 AND energy >= 15", (owner_id,)
        )
    return cur.rowcount
```

**Что наблюдать и как проверить:** Сохранённые функции не меняют данные при импорте. Выполнение начинается только при вызове команды.

- [ ] Получилось; могу объяснить место и назначение правки.
