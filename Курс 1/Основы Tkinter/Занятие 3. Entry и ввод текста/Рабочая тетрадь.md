# Рабочая тетрадь. Занятие 3. Entry и ввод текста

## Цель занятия
Научиться получать текст от пользователя через поле ввода. В нашем чате поля
ввода понадобятся для трёх вещей: номер чата, имя пользователя и текст
сообщения. На следующем занятии мы привяжем к этим полям кнопку отправки
на сервер `chat_api`.

## Шаг 1. Поле ввода
```python
import tkinter as tk

root = tk.Tk()
root.title('Вход в чат')
root.geometry('400x300')

entry = tk.Entry(root, width=40)
entry.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `entry = tk.Entry(root, width=40)` — создаёт однострочное поле для ввода текста шириной 40 символов. В него пользователь будет вводить номер чата.

## Шаг 2. Кнопка для чтения текста

## Добавляем действие по кнопке
```python
import tkinter as tk

root = tk.Tk()
root.title('Вход в чат')
root.geometry('400x300')

label = tk.Label(root, text='Номер чата:')
label.pack()

entry = tk.Entry(root, width=40)
entry.pack()

result = tk.Label(root, text='Пока не вошли')
result.pack()

def enter_chat():
    room = entry.get()
    result.config(text='Входим в чат ' + room)

button = tk.Button(root, text='Войти', command=enter_chat)
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `def enter_chat():` — объявляет функцию, которая выполнится при нажатии кнопки.
- `room = entry.get()` — получает текст из поля ввода (номер чата) и сохраняет его в `room`.
- `result.config(text='Входим в чат ' + room)` — меняет текст надписи на сообщение с номером чата.
