### Шаг 3. Создаём файл проекта и импортируем Tkinter

**Что делаем.** В папке `Курс 1/Основы Tkinter` создаём файл и называем его `main.py`. Открываем его и пишем первую строку:

```python
import tkinter as tk
```

Что здесь происходит:

- `import tkinter` — подключаем библиотеку Tkinter (она встроена в Python);
- `as tk` — даём библиотеке короткое имя `tk`, чтобы не писать каждый раз длинное `tkinter`;
- короткое имя удобно: `tk.Canvas`, `tk.Button`, `tk.Tk` — и читается легко, и пишется быстро.

**Проверь себя.** Файл `main.py` создан, в первой строке запись `import tkinter as tk`.

### Шаг 4. Создаём главное окно приложения

**Что делаем.** Добавляем следующий код:

```python
root = tk.Tk()
```

**Что здесь происходит.**

Стандарт Tkinter таков: у **каждого** приложения есть одно главное окно. Это не текстовая программа, где выполнение идёт «сверху вниз и закончилось», — GUI-приложение продолжает работать, пока пользователь не закроет окно. Чтобы создать главное окно, мы вызываем конструктор класса `Tk`: он подключается к серверу Tk (части Tkinter), создаёт окно и возвращает объект. Переменную-«хозяина» окна принято называть `root`.

**Проверь себя.** При запуске программы появляется пустое окно? Пока вы его ещё не видели — в следующем шаге напишем команды, которые окно «подержат» открытым.

- [ ] шаг выполнен

### Шаг 5. Настраиваем заголовок и размер окна

**Что делаем.** Добавляем после создания окна:

```python
root.title('Анонимный чат')
root.geometry('420x560')
```

**Подробнее о каждом методе:**

**Метод `title(text)`** — устанавливает заголовок окна.

- Зачем нужен: заголовок — это текст в верхней рамке окна; по нему пользователь понимает, какое приложение открыто.
- Параметры: `text` — строка с текстом заголовка.

**Метод `geometry(размер)`** — задаёт размер и положение окна.

- Зачем нужен: без явного размера Tk подберёт его сам по содержимому, и окно может «прыгнуть» при добавлении виджетов.
- Параметры: строка в формате `'ШИРИНАxВЫСОТА'` (латинская буква `x`), например `'420x560'`; можно добавить и положение: `'420x560+100+50'` — это сдвиг окна на 100 пикселей вправо и 50 вниз от верхнего левого угла экрана.

**Проверь себя.** При запуске окно называется «Анонимный чат» и имеет размер 420×560.

- [ ] шаг выполнен

### Шаг 6. Запускаем главный цикл и проверяем программу

**Что делаем.** Последней строкой файла добавляем:

```python
root.mainloop()
```

**Подробнее о методе `mainloop()`:**

**Зачем нужен.** Это главный («событийный») цикл приложения. Он запускает бесконечную обработку событий Tk: щелчки мышью, нажатия клавиш, прорисовку окна. Программа «засыпает» внутри этого цикла и просыпается на каждое событие. Без `mainloop()` окно бы мелькнуло и сразу закрылось.

**Параметры.** Обычно вызывается без параметров. Есть необязательный параметр `n` (число итераций цикла) — на практике не используется, достаточно просто `root.mainloop()`.

**Важно.** Всё, что написано после `mainloop()`, выполняется только после закрытия окна. Поэтому все виджеты и обработчики мы размещаем **до** этой строки.

Полный код программы:

```python
import tkinter as tk

root = tk.Tk()
root.title('Анонимный чат')
root.geometry('420x560')

root.mainloop()
```

**Проверь себя.** Окно «Анонимный чат» открывается, его можно двигать и закрывать кнопкой ✕.
