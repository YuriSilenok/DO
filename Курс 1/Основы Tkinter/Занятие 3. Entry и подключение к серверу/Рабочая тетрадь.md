### Шаг 4. Добавляем поля для ввода — виджет Entry

**Что делаем.** Добавляем после строки `info.pack()` блок из трёх полей ввода с подписями:

```python
chat_entry = tk.Entry(root, width=20)
chat_entry.pack(pady=2)

name_entry = tk.Entry(root, width=20)
name_entry.pack(pady=2)

pass_entry = tk.Entry(root, width=20, show='*')
pass_entry.pack(pady=2)
```

**Подробнее о виджете `Entry`:**

**Зачем нужен.** `Entry` — однострочное поле для ввода текста с клавиатуры. В нашем проекте оно понадобится для номера чата, имени и пароля, а на занятии 5 — для текста сообщения.

**Параметры конструктора `Entry(родитель, ...)`:**
- `width` — ширина поля в символах (не пикселях);
- `show` — символ-«маска»; `show='*'` прячет вводимые символы — так делают поля паролей;
- `font`, `fg`, `bg` — как у `Label`;
- `state` — состояние: `'normal'` (можно вводить), `'disabled'` (нельзя, серый текст), `'readonly'` (нельзя менять, но текст виден);
- `textvariable` — специальная строковая переменная `tk.StringVar`, «привязанная» к полю (понадобится на занятии 6).

**Методы объекта `Entry`:**
- `get()` — возвращает текущий текст поля (это **строка**);
- `delete(0, tk.END)` — очистить поле (от начала до конца);
- `insert(позиция, текст)` — вставить текст; `insert(0, 'привет')` вставит в начало;
- `focus_set()` — поставить курсор в поле.

**Проверь себя.** В окне появились три поля: номер чата, имя, пароль со звёздочками.

### Шаг 5. Учимся читать значения из полей

**Что делаем.** Расширяем функцию `on_enter`: читаем из полей значения с помощью `get()` и собираем строку статуса:

```python
def on_enter():
    chat_text = chat_entry.get()
    name = name_entry.get()
    password = pass_entry.get()
    info.config(text='Подключаюсь к чату {0}...'.format(chat_text))
```

**Что здесь происходит:**

- `chat_entry.get()` возвращает **строку** — например `'42'`. Для сервера номер чата — число, поэтому чуть позже сделаем `int(...)`.
- `.format(...)` подставляет значения в строку (метод строк, аналог `f'{...}'`).

**Проверь себя.** Если ввести номер и нажать кнопку, в надписи появляется «Подключаюсь к чату 42...».

### Шаг 6. Отправляем запрос join на сервер chat_api

**Что делаем.** Вставляем внутри функции `on_enter` настоящий запрос и разбор ответа:

```python
def on_enter():
    try:
        chat_text = chat_entry.get()
        name = name_entry.get()
        password = pass_entry.get()
        info.config(text='Подключаюсь к чату {0}...'.format(chat_text))

        response = requests.post(
            BASE_URL + '/chats/join',
            json={
                'chat_id': int(chat_text),
                'username': name,
                'password': password,
            },
            timeout=10,
        )
        response.raise_for_status()

        data = response.json()
        USER = name
        CHAT_ID = data['chat_id']
        info.config(
            text='Вы вошли как {0} в чат №{1} (пароль запомнен)'.format(
                USER, CHAT_ID
            )
        )
    except ValueError:
        info.config(text='Номер чата должен быть целым числом!')
    except requests.exceptions.RequestException:
        info.config(text='Ошибка сети: запустите сервер chat_api (python -m chat_api)')
```

**Подробнее о запросе `requests.post(url, ...)`:**
- Зачем нужен: `POST /chats/join` — «подключение к чату» из `chat_api`. Если чата с таким номером нет, сервер **создаст его сам**; если пользователь заходит впервые, сервер запомнит пароль.
- Параметры:
  - `url` — полный адрес `http://127.0.0.1:8000/chats/join`;
  - `json` — словарь с данными: `chat_id` (число), `username`, `password`;
  - `timeout` — сколько секунд ждать ответ, чтобы программа не «зависла» навсегда.

**Метод `response.raise_for_status()`** — проверяет код ответа: если 200 — ничего не делает, если 403/422 — выбрасывает исключение (мы его обработаем на занятии 4 через `response.status_code`).

**Метод `response.json()`** — превращает JSON-ответ сервера в словарь Python. Для `/chats/join` это `{chat_id, username, created, message}`.

**Обработка исключений `try/except`** — важна: если сервер выключен, программа не падает, а пишет понятую подсказку.

**Важно о `USER` и `CHAT_ID`:** присваивание внутри функции создаст **локальные** переменные, которые «умрут» при выходе из функции. Чтобы внешние переменные менялись, на занятии 4 добавим ключевое слово `global`. Пока просто понимаем, что эти присваивания есть.

**Проверь себя.** С запущенным сервером при заполнении полей и нажатии «Войти в чат» надпись меняется на «Вы вошли как ... в чат №...». При выключенном сервере — появляется сообщение об ошибке сети.
