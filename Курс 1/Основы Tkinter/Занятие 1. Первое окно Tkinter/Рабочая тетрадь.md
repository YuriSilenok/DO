# Рабочая тетрадь. Занятие 1. Первое окно Tkinter

## Цель занятия
Научиться создавать окно программы, задавать заголовок, размеры и запускать
цикл событий. Всё, что мы напишем дальше, станет основой **окна чата**
для сервера `chat_api` — на следующих занятиях мы подключим к нему
отправку и получение сообщений.

## Что нам понадобится
- Python
- библиотека `tkinter` (входит в состав Python)
- запущенный сервер `chat_api` (мы будем подключаться к нему позже,
  окно же можно создать прямо сейчас)

## Шаг 1. Подключаем библиотеку
```python
import tkinter as tk
```

**Пояснение к строке:**
- `import tkinter as tk` — подключает библиотеку для создания окон и даёт ей короткое имя `tk`.

## Шаг 2. Создаём главное окно
```python
import tkinter as tk

root = tk.Tk()
root.title('Мой чат')
root.geometry('400x400')
root.mainloop()
```

**Пояснения к новым строкам:**
- `root = tk.Tk()` — создаёт главное окно и сохраняет его в переменную `root`.
- `root.title('Мой чат')` — устанавливает текст в заголовке окна. Назовём наше окно «Мой чат».
- `root.geometry('400x400')` — задаёт размеры окна: ширина 400, высота 400 пикселей. Квадратное окно удобно для будущего чата.
- `root.mainloop()` — запускает цикл событий, чтобы окно оставалось открытым и реагировало на действия пользователя.

## Практика
1. Измените заголовок окна — например, добавьте номер чата.
2. Измените размеры окна.
3. Попробуйте написать несколько разных значений в `geometry`.
