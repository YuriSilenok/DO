# Рабочая тетрадь. Занятие 6. Listbox и Messagebox

## Цель занятия
Научиться выводить список элементов и показывать диалоговые окна. В нашем
чате `Listbox` покажет доступные комнаты (или последние сообщения), а
`Messagebox` — подтверждение выхода и сообщение об ошибке входа.

## Шаг 1. Listbox (список комнат)
```python
import tkinter as tk

root = tk.Tk()
root.title('Комнаты чата')
root.geometry('300x220')

listbox = tk.Listbox(root)
for room in ['Чат 1', 'Чат 2', 'Чат 3', 'Чат 4']:
    listbox.insert(tk.END, room)
listbox.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `listbox = tk.Listbox(root)` — создаёт список, в котором пользователь сможет выбирать комнаты (элементы).
- `for room in ['Чат 1', 'Чат 2', 'Чат 3', 'Чат 4']:` — по очереди перебирает названия комнат.
- `listbox.insert(tk.END, room)` — добавляет текущую комнату в конец списка.

## Шаг 2. Messagebox (окно подтверждения)
```python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title('Выход из чата')
root.geometry('300x150')

def confirm_exit():
    answer = messagebox.askyesno('Выход', 'Точно выйти из чата?')
    if answer:
        root.destroy()

button = tk.Button(root, text='Выйти из чата', command=confirm_exit)
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `from tkinter import messagebox` — подключает готовые диалоговые окна Tkinter.
- `def confirm_exit():` — объявляет функцию, которая покажет диалоговое окно.
- `answer = messagebox.askyesno('Выход', 'Точно выйти из чата?')` — показывает окно с кнопками «Да» и «Нет»; ответ сохраняется в `answer`.
- `if answer:` — если пользователь нажал «Да», выполняем выход.
- `root.destroy()` — закрывает окно программы.
