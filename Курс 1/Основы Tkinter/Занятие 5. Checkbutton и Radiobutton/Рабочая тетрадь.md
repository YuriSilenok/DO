# Рабочая тетрадь. Занятие 5. Checkbutton и Radiobutton

## Цель занятия
Научиться использовать флажки и переключатели. В нашем окне чата они
управляют настройками входа: флажок показывает пароль, а переключатели
выбирают номер чата.

## Шаг 1. Checkbutton (флажок)
```python
import tkinter as tk

root = tk.Tk()
root.title('Настройки входа')
root.geometry('400x220')

show_password = tk.BooleanVar()
checkbox = tk.Checkbutton(root, text='Показывать пароль', variable=show_password)
checkbox.pack()

label = tk.Label(root, text='Пароль скрыт')
label.pack()

def update_status():
    if show_password.get():
        label.config(text='Пароль виден')
    else:
        label.config(text='Пароль скрыт')

checkbox.config(command=update_status)
root.mainloop()
```

**Пояснения к новым строкам:**
- `show_password = tk.BooleanVar()` — создаёт переменную Tkinter для хранения значения `True` или `False`.
- `checkbox = tk.Checkbutton(root, text='Показывать пароль', variable=show_password)` — создаёт флажок, связанный с переменной `show_password`.
- `def update_status():` — объявляет функцию для обновления статуса.
- `if show_password.get():` — проверяет, установлен ли флажок.
- `else:` — задаёт действие для случая, когда условие выше не выполнено.

## Шаг 2. Radiobutton (переключатель номера чата)
```python
import tkinter as tk

root = tk.Tk()
root.title('Выбор чата')
root.geometry('400x240')

room = tk.StringVar(value='1')

rooms = ['1', '2', '3']
for value in rooms:
    tk.Radiobutton(root, text='Чат ' + value, variable=room, value=value).pack()

label = tk.Label(root, text='Выбран чат 1')
label.pack()

def show_choice():
    label.config(text='Выбран чат ' + room.get())

button = tk.Button(root, text='Показать выбор', command=show_choice)
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `room = tk.StringVar(value='1')` — создаёт переменную для номера выбранного чата и задаёт начальный выбор «чат 1».
- `rooms = ['1', '2', '3']` — создаёт список доступных номеров чатов.
- `for value in rooms:` — по очереди перебирает каждый номер из списка.
- `def show_choice():` — объявляет функцию для отображения выбранного значения.
