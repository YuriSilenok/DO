## Шаг 1. Создаём поля и кнопку
```python
import tkinter as tk

root = tk.Tk()
root.title('Отправка сообщения')
root.geometry('400x350')

label_room = tk.Label(root, text='Номер чата:')
label_room.pack()
entry_room = tk.Entry(root, width=40)
entry_room.pack()

label_name = tk.Label(root, text='Имя:')
label_name.pack()
entry_name = tk.Entry(root, width=40)
entry_name.pack()

label_password = tk.Label(root, text='Пароль:')
label_password.pack()
entry_password = tk.Entry(root, width=40, show='*')
entry_password.pack()

label_text = tk.Label(root, text='Сообщение:')
label_text.pack()

entry_text.pack()

result.pack()
```

**Пояснения к новым строкам:**
- `entry_password = tk.Entry(root, width=40, show='*')` — поле пароля, где вводимые символы скрываются звёздочками.
- `label_room`, `label_name`, `label_password`, `label_text` — подписи к полям. Раньше здесь были переменные `label1`, `label2` и `result`.

## Шаг 3. Отправляем сообщение в чат
```python
import json
import tkinter as tk
import urllib.request

SERVER = 'http://127.0.0.1:8000'

root = tk.Tk()
root.title('Отправка сообщения')
root.geometry('400x350')

label_room = tk.Label(root, text='Номер чата:')
label_room.pack()
entry_room = tk.Entry(root, width=40)
entry_room.pack()

label_name = tk.Label(root, text='Имя:')
label_name.pack()
entry_name = tk.Entry(root, width=40)
entry_name.pack()

label_password = tk.Label(root, text='Пароль:')
label_password.pack()
entry_password = tk.Entry(root, width=40, show='*')
entry_password.pack()

label_text = tk.Label(root, text='Сообщение:')
label_text.pack()
entry_text = tk.Entry(root, width=40)
entry_text.pack()

result = tk.Label(root, text='Готов к отправке')
result.pack()

def send_message():
    room = entry_room.get()
    name = entry_name.get()
    password = entry_password.get()
    text = entry_text.get()

    body = json.dumps({
        'chat_id': int(room),
        'username': name,
        'password': password,
        'text': text,
    }).encode('utf-8')

    request = urllib.request.Request(
        SERVER + '/chats/send',
        data=body,
        headers={'Content-Type': 'application/json'},
        method='POST',
    )
    with urllib.request.urlopen(request, timeout=5) as response:
        answer = json.load(response)

    result.config(text='Отправлено!')
    entry_text.delete(0, tk.END)

button = tk.Button(root, text='Отправить', command=send_message)
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `import json` и `import urllib.request` — подключают модули для работы с JSON и HTTP-запросами.
- `SERVER = 'http://127.0.0.1:8000'` — адрес сервера `chat_api`.
- `body = json.dumps({...}).encode('utf-8')` — собирает данные сообщения в JSON-строку и превращает её в байты.
- `urllib.request.Request(...)` — создаёт HTTP POST-запрос с нужными заголовками.
- `urllib.request.urlopen(request, timeout=5)` — отправляет запрос и получает ответ сервера.
- `json.load(response)` — разбирает ответ сервера в словарь.
- `entry_text.delete(0, tk.END)` — очищает поле сообщения после отправки.
