# Рабочая тетрадь. Занятие 2. Label и Button

## Цель занятия
Научиться добавлять текст и кнопки на форму. Наша форма — это окно будущего
чата: сверху подпись-заголовок, а под ней кнопка входа в чат.

## Шаг 1. Создаём надпись
```python
import tkinter as tk

root = tk.Tk()
root.title('Мой чат')
root.geometry('400x300')

title = tk.Label(root, text='Добро пожаловать в чат!')
title.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `title = tk.Label(root, text='Добро пожаловать в чат!')` — создаёт текстовую надпись внутри окна. Это шапка нашего чата.
- `title.pack()` — размещает надпись в окне.

## Шаг 2. Добавляем кнопку
```python
import tkinter as tk

root = tk.Tk()
root.title('Мой чат')
root.geometry('400x300')

title = tk.Label(root, text='Добро пожаловать в чат!')
title.pack()

button = tk.Button(root, text='Войти в чат')
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `button = tk.Button(root, text='Войти в чат')` — создаёт кнопку с текстом «Войти в чат». На следующих занятиях по нажатию этой кнопки мы будем подключаться к серверу `chat_api`.
