### Шаг 3. Добавляем первую надпись — виджет Label

**Что делаем.** Вставляем между `root.geometry(...)` и `root.mainloop()` следующий код:

```python
title = tk.Label(root, text='Добро пожаловать в чат!')
title.pack()
```

**Подробнее о виджете `Label`:**

**Зачем нужен.** `Label` — простейший виджет Tkinter для показа текста или картинки. Это «вывеска» приложения: заголовки, подписи к полям, статусы.

**Параметры конструктора `Label(родитель, ...)`:**

- `родитель` (обязательный, первый аргумент) — окно или контейнер, в котором живёт виджет; у нас это `root`;
- `text` — текст надписи;
- `font` — шрифт, например `('Arial', 14)` и `font=('Arial', 14, 'bold')`;
- `fg` (`foreground`) — цвет текста, например `'navy'`, `'#003366'`;
- `bg` (`background`) — цвет фона, например `'lightyellow'`, `'#f0f0f0'`;
- `padx`, `pady` — внутренние отступы в пикселях;
- `width`, `height` — размер в «единицах текста» (символах и строках), не в пикселях.

**Проверь себя.** При запуске в верхней части окна появилась надпись.

- [ ] шаг выполнен

### Шаг 4. Размещаем виджеты методом pack()

**Что делаем.** Разбираемся со строкой `title.pack()` и добавляем каркас экрана входа:

```python
welcome = tk.Label(root, text='Добро пожаловать в чат!', font=('Arial', 14))
welcome.pack(pady=10)

info = tk.Label(root, text='Введите номер чата, имя и пароль')
info.pack()

enter_btn = tk.Button(root, text='Войти в чат')
enter_btn.pack(pady=10)
```

**Подробнее о методе `pack():`**

**Зачем нужен.** `pack()` — геометр-менеджер, который размещает виджеты в окне один за другим: сверху вниз (по умолчанию) или слева направо. Его главный плюс — простота: окно само подбирает размеры.

**Параметры метода `pack(...)`:**
- `side` — сторона, у которой прижимается виджет: `'top'`, `'bottom'`, `'left'`, `'right'` (по умолчанию `'top'`);
- `padx`, `pady` — отступы от соседних виджетов в пикселях (внешние отступы);
- `fill` — растяжение: `'x'` по ширине, `'y'` по высоте, `'both'` по обеим осям, `'none'` — не растягивать;
- `expand` — `True`/`False`: разрешить виджету занимать всё свободное место;
- `anchor` — позиция при свободном месте: `'n'`, `'s'`, `'e'`, `'w'`, `'center'` и комбинации.

**Проверь себя.** В окне появились две надписи и кнопка «Войти в чат», расположенные друг под другом.

- [ ] шаг выполнен

### Шаг 5. Учим кнопку реагировать на нажатие

**Что делаем.** Пишем функцию-обработчик и связываем её с кнопкой параметром `command`:

```python
def on_enter():
    info.config(text='Сейчас подключимся к серверу...')

enter_btn = tk.Button(root, text='Войти в чат', command=on_enter)
```

**Подробнее о параметре `command`:**
- Зачем нужен: определяет, что произойдёт при клике по кнопке.
- Как работает: Tk вызывает указанную функцию при каждом нажатии.
- **Важно:** передаётся **имя** функции без скобок: `command=on_enter`. Если написать `command=on_enter()`, функция выполнится один раз **сразу при создании кнопки**, и кнопка ничего не будет делать при кликах.
- Можно передавать и готовую функцию из модуля: `command=root.quit`.
- Если нужно «запомнить» аргументы — используют `lambda:`, с ним познакомимся на занятии 5.

**Подробнее о методе `config`:**
- Зачем нужен: изменяет параметры уже созданного виджета «на лету».
- Параметры: те же, что у конструктора. Пример: `label.config(text='Новый текст', fg='red')`.
- Метод `configure` — полный синоним `config`.

**Проверь себя.** При нажатии на кнопку текст под ней меняется на «Сейчас подключимся к серверу...».

- [ ] шаг выполнен

### Шаг 6. Проверяем программу целиком

**Что делаем.** Запускаем `main.py`. Полный код на этом занятии:

```python
import tkinter as tk

root = tk.Tk()
root.title('Анонимный чат')
root.geometry('420x560')

welcome = tk.Label(root, text='Добро пожаловать в чат!', font=('Arial', 14))
welcome.pack(pady=10)

info = tk.Label(root, text='Введите номер чата, имя и пароль')
info.pack()

def on_enter():
    info.config(text='Сейчас подключимся к серверу...')

enter_btn = tk.Button(root, text='Войти в чат', command=on_enter)
enter_btn.pack(pady=10)

root.mainloop()
```

**Проверь себя.** Всё работает: окно открывается, надписи видны, кнопка меняет текст нижней надписи при нажатии.
