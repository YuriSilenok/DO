## Классная работа

### Шаг 1. Сначала устанавливаем Termux

Выберите [F-Droid](https://f-droid.org/packages/com.termux/) или [официальные релизы](https://github.com/termux/termux-app/releases), учитывая требования конкретной сборки к Android. Установите приложение. Приложение и плагины берите из одного источника: подписи разных сборок несовместимы.

**Проверка:** Termux открывается и показывает приглашение терминала.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Готовим Python

По очереди выполните `pkg update`, `pkg upgrade`, затем `pkg install python nano termux-tools`. Прочитайте запросы подтверждения. Проверьте `python --version`. Не обновляйте системный pip командой pip install --upgrade pip.

**Проверка:** Python 3 запускается без ошибок.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Ориентируемся в папках

Выполните `pwd`, `ls`. Создайте каталог `mkdir -p ~/bot`, перейдите `cd ~/bot`. Символ ~ означает домашнюю папку. Здесь храним рабочие файлы, а не в общем хранилище телефона.

**Проверка:** pwd заканчивается на /home/bot.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Переносим свой файл

Скопируйте уже написанный вами bot.py без секрета на телефон как файл, например по USB. Сохраните его в «Загрузки». Выполните `termux-setup-storage` и разрешите доступ, затем `cp ~/storage/downloads/bot.py ~/bot/`. Это перенос собственного результата, а не готового решения из тетради. Токен переносить вместе с файлом не нужно.

**Проверка:** ls в ~/bot показывает bot.py; getpass остался в коде.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Готовим окружение

В ~/bot выполните `python -m venv .venv`, затем `source .venv/bin/activate` и `python -m pip install vk_api`. При новом сеансе повторяется активация, а не создание среды. Окружение Windows на телефон не копируйте.

**Проверка:** команда `python -c "import vk_api"` завершается без ошибки.

- [ ] Получилось; могу объяснить изменение.

### Шаг 6. Запускаем один экземпляр

Остановите бота на компьютере через Ctrl+C. На телефоне выполните `termux-wake-lock`, затем `python bot.py`; введите токен в скрытом приглашении. Проверьте кнопки и вопрос. Два процесса одного бота одновременно в учебном проекте не запускаем.

**Проверка:** бот отвечает с телефона при остановленном процессе Windows.

- [ ] Получилось; могу объяснить изменение.

### Шаг 7. Останавливаем и повторяем

Нажмите Ctrl+C в Termux, выполните `termux-wake-unlock`. Запустите бота повторно и снова остановите. Wake lock уменьшает засыпание процессора, но не обеспечивает работу 24/7: Android, связь и батарея могут прервать процесс. Для постоянной работы нужен отдельный хостинг.

**Проверка:** вы умеете запускать и останавливать бота без переустановки.

- [ ] Получилось; могу объяснить изменение.

## Домашняя работа · небольшая доработка

Добавьте перед циклом вывод «Магический шар запущен на Android» в телефонной копии. Запишите в памятку команды перехода в каталог, активации, запуска и остановки. Проверьте один повторный запуск по этой памятке. Если работаете на ПК — измените сообщение на «…на компьютере» и выполните ту же проверку.
