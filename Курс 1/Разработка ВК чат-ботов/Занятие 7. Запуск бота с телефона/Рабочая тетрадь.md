## О занятии

**Цели занятия**

1. Понять, как запустить бота не на компьютере, а на своём телефоне.
2. Установить на телефон приложение Termux — терминал Linux для Android.
3. Установить в Termux Python и библиотеку `vk_api`.
4. Скопировать код бота на телефон и запустить его.
5. Разобраться, как держать бота запущенным как можно дольше.

**Что понадобится**

- Рабочий бот с занятия 6 (`bot.py` «Магического шара»).
- Смартфон на **Android** (версия 7 и выше) с выходом в интернет.
- Доступ к вашему коду: файл `bot.py` в облаке (Google Диск, Яндекс Диск), в сообщении самому себе или на почте.

**Как устроена рабочая тетрадь**

- **Часть 1. Классная работа** — пошаговая инструкция. Выполняем шаги вместе с преподавателем, вчитываясь в пояснения.
- **Часть 2. Домашняя работа** — повторение материала на похожем примере. Где возможна вариативность, задание можно выполнить по-своему — такие условия помечены словом **«Вариативность»**.

**Сквозной проект**

До сих пор «Магический шар» работал, только пока запущен на вашем компьютере: закрыли VS Code или выключили ноутбук — бот «уснул». Сегодня мы сделаем новый шаг: научимся запускать бота **прямо на телефоне** с помощью приложения Termux. Теперь бота можно взять с собой куда угодно — он живёт у вас в кармане и отвечает, даже когда под рукой нет компьютера. Ограничения честно обсудим: телефон не может работать без остановки, как настоящий сервер, — но на время демонстрации и игр бота с телефона более чем достаточно.

# Часть 1. Классная работа

### Шаг 1. Знакомимся с Termux

**Что делаем.** Вместе с преподавателем разбираемся, что такое Termux и почему бота можно запустить на телефоне.

**Пояснение.** Ваш телефон — это уже компьютер, просто маленький. На нём есть процессор, память и интернет. Termux — это бесплатное приложение для Android, которое открывает на телефоне **терминал Linux**: чёрное окно, куда вводятся команды, как в командной строке Windows. Раньше мы писали команды для Python в VS Code на компьютере — теперь те же команды можно набирать на телефоне.

Termux умеет:
- устанавливать **Python** (команда `pkg install python`);
- устанавливать библиотеки через **pip**, в том числе `vk_api`;
- запускать `.py`-файлы прямо на устройстве.

Сравните с кухней: VS Code — это как большая кухня на кухне дома (много места, удобно готовить). Termux — это походная горелка: она компактнее и слабее, но с её помощью можно приготовить то же самое блюдо где угодно.

**Проверь себя.** Вы можете объяснить своими словами, зачем боту телефон, и чем Termux похож на терминал на компьютере.

### Шаг 2. Устанавливаем Termux

**Что делаем.** Устанавливаем приложение Termux на телефон. Правильный источник — приложение **F-Droid** (каталог бесплатных приложений) или официальный сайт терминала. Внутри F-Droid находим Termux и нажимаем «Установить».

**Пояснение.** Termux нет в обычном магазине Google Play — там лежит устаревшая версия. Поэтому используем F-Droid: это что-то вроде «магазина приложений», в котором живёт свежий Termux. Скачать F-Droid можно с его официального сайта (fdroid.org). Если преподаватель подготовил установочный файл заранее — можно установить прямо с него.

**⚠️ Важно.** Скачиваем приложения только с официальных источников, которые называет преподаватель. Сторонние сайты с «улучшенной версией Termux» могут навредить телефону.

**Проверь себя.** Приложение Termux установлено, иконка появилась на экране телефона.

### Шаг 3. Обновляем пакеты и устанавливаем Python

**Что делаем.** Открываем Termux. При первом запуске появится приглашение командной строки. Обновляем список пакетов и устанавливаем Python:

```
pkg update
pkg install -y python
python --version
```

**Пояснение.** `pkg` — «магазин приложений» Termux: через него устанавливаются программы внутри терминала. `pkg update` — обновление «витрины магазина» (списка доступных программ). `pkg install -y python` — установка Python; флаг `-y` отвечает «да» на все вопросы автоматически. После установки команда `python --version` показывает номер версии — значит, Python готов. Обратите внимание: в Termux команда называется `python` (как на Windows), а не `python3`. Все команды вводим на виртуальной клавиатуре телефона — она такая же, как в обычном чате.

**Проверь себя.** `python --version` показал номер версии Python 3 без ошибок.

### Шаг 4. Первые команды в Termux

**Что делаем.** Выполняем в Termux первые команды. Команда `whoami` — «кто я», покажет текущего пользователя. Команда `pwd` — «где я», покажет текущую папку. Команда `ls` — «что здесь лежит», покажет список файлов.

```
whoami
pwd
ls
```

**Пояснение.** Эти три команды — как «знакомство с новым домом»: узнаём, кто мы (пользователь), где находимся (папка) и что вокруг (файлы). Команды простые, но именно на них строятся все дальнейшие действия. Сравните с Windows: `ls` похожа на `dir` в командной строке Windows, которая показывает список файлов. Со временем эти команды войдут в привычку.

**Проверь себя.** `whoami` показал имя пользователя (например, `u0_a123`), `pwd` показал что-то вроде `/data/data/com.termux/files/home`, `ls` не выдал ошибки (список может быть пустым).

### Шаг 5. Настраиваем клавиатуру смартфона

**Что делаем.** Проверяем, что в Termux появляется **дополнительный ряд клавиш**: цифры и стрелки. Если клавиатура не разворачивается, нажимаем и удерживаем, затем в настройках Termux открываем «Keyboard» и включаем «Show Extra Keys». Разрешаем приложению показывать уведомления — так нам будет проще видеть, что бот работает.

**Пояснение.** На маленьком экране телефона обычной клавиатуры не хватает: боту нужны стрелки (пролистывать историю команд) и цифры (например, для `vk_api`). Дополнительный ряд — как «функциональные клавиши» на большой клавиатуре. Termux также умеет показывать уведомление о запущенном процессе — эту «лампачку» мы включим позже, на шаге 8.

### Шаг 6. Создаём папку проекта и переносим код на телефон

**Что делаем.** Создаём в Termux рабочий каталог и кладём в него файл `bot.py`. Код переносим удобным способом:

**Способ А (через сообщение самому себе).** На компьютере открываем `bot.py` в VS Code, копируем весь текст и отправляем себе в ВК или Telegram «избранное». На телефоне открываем это сообщение, копируем текст и вставляем в новый файл прямо в Termux:

```
mkdir bot
cd bot
nano bot.py
```

В открывшемся редакторе `nano` вставляем скопированный текст (долгое нажатие на экран → «Вставить»), сохраняем (`Ctrl+O`, Enter) и выходим (`Ctrl+X`).

**Способ Б (через файл).** Кладём `bot.py` в облако (Google Диск, Яндекс Диск), скачиваем на телефон, затем перемещаем в папку Termux командой:

```
mkdir bot
cd bot
termux-setup-storage
cp /sdcard/Download/bot.py .
```

`termux-setup-storage` один раз открывает доступ Termux к файлам телефона; файл из папки «Загрузки» оказывается в рабочем каталоге под именем `bot.py`.

**⚠️ Важно.** Перед запуском **замените** в `bot.py` токен на настоящий, если в коде стоит заглушка. Помните: это «ключ от квартиры» бота.

**Проверь себя.** Команда `ls` в папке `bot` показывает файл `bot.py`.

### Шаг 7. Устанавливаем библиотеку vk_api

**Что делаем.** Устанавливаем в Termux библиотеку `vk_api` — она умеет подключаться к серверам ВКонтакте:

```
pip install vk_api
```

**Пояснение.** `pip` — «менеджер библиотек» Python: устанавливает готовые модули, в том числе `vk_api`. На компьютере мы ставили её в VS Code, теперь ставим в Termux. После установки библиотеку станет видно и в этом терминале — модуль `from vk_api.longpoll import VkLongPoll, VkEventType` заработает так же, как на компьютере.

**Проверь себя.** Установка завершилась строкой `Successfully installed vk_api-...` (номер версии может отличаться) и без ошибок в конце.

### Шаг 8. Запускаем бота с телефона и держим его включённым

**Что делаем.** Запускаем бота и включаем «режим неспящего телефона», чтобы Termux не уснул:

```
cd ~/bot
termux-wake-lock
python bot.py
```

**Пояснение.** `cd ~/bot` — «перейти в папку» (как двойной клик по папке в Windows). `termux-wake-lock` — разрешение Termux работать даже когда экран выключится (это «ночная смена»: телефон не уходит в глубокий сон, пока запущен терминал). `python bot.py` — запустить бота. Если всё сделано верно, вы увидите «Бот запущен!» — и бот начнёт отвечать из ВКонтакте прямо с вашего телефона.

Как только в чате сообщества появится сообщение, Termux напечатает строку «Новое сообщение: ...» — это живой лог, как в окне VS Code. **Не закрывайте Termux и не выключайте экран надолго** — именно так «держат» бота на телефоне. Если экран погас, поднесите палец или снова откройте приложение — бот продолжит работать.

**⚠️ Важно.** Токен на телефоне — такой же секрет, как на компьютере. Никому не показываем и не отправляем скриншоты кода с токеном.

**Проверь себя.** Напишите «Магическому шару» сообщение во ВКонтакте — он отвечает, а в Termux видны строки «Новое сообщение: ...».
