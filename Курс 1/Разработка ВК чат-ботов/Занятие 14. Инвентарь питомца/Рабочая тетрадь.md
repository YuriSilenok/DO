## Классная работа

### Шаг 1. Планируем таблицу

У одного питомца много видов предметов. Не добавляйте столбцы «яблоко1», «яблоко2». Рядом с созданием pets добавьте CREATE TABLE IF NOT EXISTS inventory с полями owner_id INTEGER NOT NULL, item TEXT NOT NULL, quantity INTEGER NOT NULL DEFAULT 0 CHECK(quantity >= 0) и составным PRIMARY KEY (owner_id, item). Одна строка означает количество одного вида предмета у одного владельца. Сохраните создание через commit.

**Проверка:** нарисуйте строки: владелец 1/корм/3 и владелец 1/мяч/1; повтор пары запрещён.

### Шаг 2. Выдаём подарок один раз

Добавьте команду «Подарок». Сначала проверьте наличие питомца. Затем выполните INSERT OR IGNORE INTO inventory (owner_id, item, quantity) VALUES (?, ?, ?) с параметрами (user_id, "корм", 3) и commit. По rowcount сообщите, выдан ли подарок. Строку с нулевым количеством позже не удаляем: её наличие помнит, что стартовый подарок уже получен.

**Проверка:** два вызова дают три корма суммарно, а не шесть.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Читаем список
