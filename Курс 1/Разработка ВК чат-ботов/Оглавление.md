# Разработка ВК чат-ботов · рабочие тетради

**01–08 — «Магический шар». 09–14 — завершённый проект «Тамагочи» из шести последовательных тетрадей.** Число этапов определяется устройством игры, а не требованием дойти до 16.

Код можно копировать **по одному блоку до 10 строк**. Перед ним указано место вставки или замены, назначение и причина расположения. После блока выполните проверку. Полного исходника бота одним блоком нет; домашняя работа немного развивает тему текущего этапа.

## Последовательность проекта «Тамагочи»

09 — файл БД, таблица, создание и чтение. 10 — личный профиль в VK. 11 — кормление, игра, отдых. 12 — потребности снижаются со временем и после перезапуска. 13 — своё имя, характер и подсказки. 14 — проверка пути игрока и сохранения.

У питомца три показателя: сытость, настроение и энергия, каждый от 0 до 100. Раз в 10 минут они снижаются на 5, 3 и 2; прошедшее время учитывается при следующем сообщении. Кормление восстанавливает сытость, отдых — энергию, игра — настроение. Питомец не погибает: нули можно восстановить уходом. Бесконечный корм позволяет играть без отдельного магазина. Нет обещаний фоновых уведомлений, режима сна и инвентаря: это возможные расширения, не обязательные части этой версии.

## Как работать

Открывайте папку и тетрадь по номеру с ведущим нулём: имена папок и файлов сортируются от 01 по порядку. Выполняйте этапы последовательно; домашнюю доработку делайте в своём проекте. В первых восьми тетрадях код шара хранится в bot.py. В продолжении pet_db.py содержит функции SQLite, pet_bot.py — работу с VK, db_check.py — небольшие проверки; tamagotchi.db хранит состояние. Старую pets.db новый проект не использует.

В Windows используйте Python окружения .venv из папки проекта; в Termux — активированную среду телефона. Для переноса тамагочи нужны оба файла pet_bot.py и pet_db.py и, если сохраняете игру, tamagotchi.db после остановки бота. Саму .venv между устройствами не копируйте. Запускайте один процесс бота.

## Рабочие области VS Code

- **Explorer / Проводник** слева: открыть или создать нужный файл. Проект открывается через File → Open Folder; файлы бота лежат рядом с `.venv`, не внутри неё.
- **Редактор** в центре: Python-код в `.py`, SQL — строкой внутри `execute`. Сохраняйте через `Ctrl+S`.
- **TERMINAL** внизу: Terminal → New Terminal, профиль PowerShell. Здесь вводятся команды установки и запуска; после команды нажимайте `Enter`. Перед запуском `Get-Location` должен показывать папку проекта. Команды Windows начинаются с `.\.venv\Scripts\python.exe`.
- **Браузер / приложение VK**: настройки сообщества и сообщения боту. Текст «Кормить» отправляется в диалог, а не в PowerShell.
- **Termux на Android** в занятии 7: команды телефона выполняются в нём, отдельно от терминала VS Code.

Каждый шаг указывает рабочую область, место изменения, порядок действий, наблюдаемый результат и проверку. Перед правкой работающего бота нажмите `Ctrl+C` в его TERMINAL; после сохранения запустите заново. Приглашение `PS …>` означает готовность PowerShell принять команду; `>>>` — открытый интерактивный Python, из него выходят через `exit()`.

## Секреты и данные

Токен вводится при запуске через getpass и не хранится в исходнике. Не отправляйте его преподавателю или в общий чат. ID сообщества — публичное число. При утечке ключ отзывают в VK. Базы с реальными профилями и их копии не добавляйте в репозиторий; для демонстрации используйте учебные данные.

## Дополнительное чтение
