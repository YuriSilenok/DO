# Иллюстрации к рабочей тетради (для преподавателя)

Этот файл — инструкция для **преподавателя**. Ученик не вставляет скриншоты сам: иллюстрации готовит преподаватель **до раздачи тетрадей**. В тексте тетради про скриншоты **не упоминается** — картинки уже стоят в нужных местах.

**Как подготовить.**

1. Выполните занятие сами или используйте образец экрана.
2. Сохраните скриншоты в эту папку (`images`) с именами из таблицы ниже.
3. Проверьте, что все файлы лежат на своих местах.

**Занятие 4 — «Первый код бота „Магический шар“»**

| № | Что показать на скриншоте | Имя файла |
|---|---|---|
| Рис. 1 | Папка проекта: `magic_ball.py` и `bot.py` | `shag-01-dva-fajla.png` |
| Рис. 2 | Установка библиотеки vk_api в терминале | `shag-02-pip-install.png` |
| Рис. 3 | Код подключения к сообществу (токен замазан) | `shag-03-podklyuchenie.png` |
| Рис. 4 | Цикл обработки событий в `bot.py` | `shag-04-cikl.png` |
| Рис. 5 | Код отправки ответа (`random.choice`) | `shag-05-otvet.png` |
| Рис. 6 | Список предсказаний и случайный выбор | `shag-06-random.png` |
| Рис. 7 | Переписка с ботом: вопросы и ответы | `shag-07-test.png` |

> ВАЖНО: на скриншотах № 3 и любых других, где виден код, токен должен быть замазан.

**В тетради** изображения уже подставлены после каждого шага. Проверьте, что файлы лежат в этой папке, — и тетрадь готова к раздаче.
