## Как выполнять действия в VS Code

1. Откройте **File → Open Folder / Файл → Открыть папку** и выберите свою папку `vk_bot`. Слева в **Explorer / Проводник** (`Ctrl+Shift+E`) находятся файлы, в центре — редактор выбранного файла. Файлы `.py` создавайте в корне `vk_bot`, не внутри `.venv`.
2. Код Python вводите в центральный редактор файла `.py`, затем нажимайте `Ctrl+S`. Точка на вкладке означает несохранённые изменения. Фрагменты SQL помещайте в кавычках в аргументы `execute` в Python-файле; их не вводят как команды PowerShell.
3. Команды установки и запуска вводите внизу: **Terminal → New Terminal / Терминал → Создать терминал**. В этой тетради для Windows используется **PowerShell**. Щёлкните после приглашения `PS …>`, наберите команду без самого приглашения и нажмите `Enter`. Панели **Output / Вывод** и **Debug Console / Консоль отладки** для этих команд не подходят.
4. Проверьте текущую папку командой `Get-Location`: путь должен оканчиваться на `vk_bot`. Командой `Get-ChildItem` посмотрите файлы: нужный `.py` и папка `.venv` должны быть здесь. Если папка другая, откройте правильную через File → Open Folder и создайте новый терминал. Если видите `>>>`, открыт интерактивный Python: введите `exit()` и Enter, чтобы вернуться к PowerShell.
5. После создания окружения запускайте нужный файл командой из блока ниже. Начальное `.\` означает «из текущей папки». Если PowerShell активировал среду автоматически, прямой путь всё равно подходит. Если `.venv` ещё нет, сначала выполните создание среды из занятия 2.

```powershell
.\.venv\Scripts\python.exe bot.py
```

6. Пока бот работает, приглашение `PS …>` не возвращается: терминал занят программой. Вопросы и команды боту отправляйте в **диалоге с сообществом VK**. Консольной программе ответ на `input` вводите в том же TERMINAL после её вопроса. Ключ вводится только после приглашения `Токен сообщества:`; символы `getpass` не отображаются.
7. Перед новой правкой щёлкните в TERMINAL и нажмите `Ctrl+C`, дождитесь приглашения PowerShell. Исправьте файл, сохраните `Ctrl+S`, снова выполните команду запуска. Работающая программа не подхватывает сохранённые изменения сама. Ошибки Python читаем в TERMINAL: последняя строка — тип и описание, выше — файл и номер строки. Кнопка Problems / Проблемы помогает найти синтаксические замечания, но не заменяет запуск.

## Классная работа

### Шаг 1. Готовим файл и библиотеку

**Где работаем:** VS Code: Explorer для bot.py, TERMINAL PowerShell для установки.

**Действие:** Сохраните консольный черновик и создайте `bot.py`. Из терминала проекта выполните `.venv\Scripts\python.exe -m pip install vk_api`. Затем проверьте импорт командой `.venv\Scripts\python.exe -c "import vk_api; print('OK')"`. Сообщение Requirement already satisfied также означает, что пакет установлен.

**Порядок выполнения и ориентиры:** Создайте bot.py рядом с magic_ball.py. Откройте Terminal → New Terminal. Проверьте Get-Location: открыта vk_bot. Команду pip из задания введите после PS и Enter; дождитесь возврата приглашения, затем выполните команду проверки импорта.

**Что должно получиться:** В терминале видны завершение установки и отдельная строка OK. Если ModuleNotFoundError, проверьте, что и pip, и запуск используют Python из .venv.

**Проверка:** импорт выводит OK без ошибки.

### Шаг 2. Отделяем секрет

**Где работаем:** Центральный редактор bot.py: верхняя часть файла.

**Действие:** В начале bot.py подключите `getpass` из модуля getpass. Получите токен через вызов `getpass("Токен сообщества: ")`, сохраните его в `token`. При запуске ввод скрыт; это не зависание. Создайте `group_id` с положительным числовым ID. Настоящий токен в файле не записываем.

**Порядок выполнения и ориентиры:** В первой группе строк запишите импорт from getpass import getpass. Под импортами создайте token через вызов getpass, затем group_id. Сохраните Ctrl+S. Проверьте запуск командой `.\.venv\Scripts\python.exe bot.py` в TERMINAL; после приглашения вставьте токен и нажмите Enter.

**Что должно получиться:** Символы токена не отображаются. На этом промежуточном шаге программа завершится сразу после чтения ключа: слушатель пока не написан.

**Проверка:** в файле есть запрос токена, но нет самого ключа.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Создаём подключение

**Где работаем:** Редактор bot.py: импорты наверху, подключение после token и group_id.

**Действие:** Рядом с импортами подключите `vk_api`, а из `vk_api.bot_longpoll` — `VkBotLongPoll` и `VkBotEventType`. После ID создайте `vk` вызовом `vk_api.VkApi(token=token)`. Затем создайте `longpoll` выражением `VkBotLongPoll(vk, group_id)`. Пока используем версию API библиотеки; если в учебном сообществе настроена другая, преподаватель согласует `api_version` и настройки VK. После создания longpoll выведите «Бот запущен». Запустите файл через Python окружения.

**Порядок выполнения и ориентиры:** Добавьте импорты рядом с getpass, а создание vk и longpoll — ниже group_id, без отступов. После них добавьте вывод о запуске. Сохраните, в TERMINAL запустите `.\.venv\Scripts\python.exe bot.py` и введите токен.

**Что должно получиться:** Появилось «Бот запущен». Пока цикла нет, приглашение PS вернётся — это нормально. Если есть traceback, читайте последнюю строку ошибки.

**Проверка:** подключение проходит; если 5 — проверьте ключ, если 15 — права и настройки сообщества. Сам токен не показывайте.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Слушаем личный диалог

**Где работаем:** Редактор bot.py: новый цикл после сообщения о запуске; проверка в браузере.

**Действие:** После подключения создайте цикл `for event in longpoll.listen():`. Внутри обрабатывайте только `event.type == VkBotEventType.MESSAGE_NEW`. Возьмите `message = event.message`. Пропустите событие через `continue`, если `message.peer_id != message.from_id` или `message.from_id <= 0`: беседы пока не поддерживаем. Оставшиеся строки находятся внутри цикла и проверки MESSAGE_NEW. Сохраните `message.from_id` в `user_id`, а `message.text.strip().lower()` — в `user_text`. Временно печатайте только «Получено сообщение», без чужого текста.

**Порядок выполнения и ориентиры:** Цикл начинается без отступа. Проверка MESSAGE_NEW внутри него имеет 4 пробела, её тело — 8. Условие пропуска находится в теле MESSAGE_NEW; его continue — с 12 пробелами. Извлечение user_id, user_text и временный print верните на 8 пробелов. Сохраните, запустите бота в TERMINAL, затем в браузере отправьте «Тест» в личный диалог сообщества.

**Что должно получиться:** Теперь приглашение PS не возвращается: программа слушает события. В TERMINAL появилась «Получено сообщение». Ответа в VK ещё нет. Перед правкой остановите слушатель Ctrl+C в терминале.

**Проверка:** личное сообщение вызывает отметку в терминале. Беседы не обрабатываются.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Переносим предсказания

**Где работаем:** Редактор: вкладки magic_ball.py и bot.py.

**Действие:** Перенесите из magic_ball.py импорт random и список answers. Импорт — наверх, список — перед циклом, без input и консольного вывода. Внутри обработки сообщения получите `reply = random.choice(answers)`.

**Порядок выполнения и ориентиры:** Откройте исходный список в magic_ball.py и перенесите только список в bot.py перед циклом. Подключите random вверху. Присваивание reply разместите в теле MESSAGE_NEW после user_text, с тем же отступом 8 пробелов. Для проверки временно выведите reply через print сразу после выбора.

**Что должно получиться:** При сообщении в VK в TERMINAL видно одно предсказание из списка. После проверки удалите временный print(reply), отметку получения можно оставить.

**Проверка:** подготовка выполняется один раз, выбор — на каждое сообщение.

- [ ] Получилось; могу объяснить изменение.

### Шаг 6. Отправляем ответ

**Где работаем:** Редактор bot.py: сразу после присваивания reply внутри MESSAGE_NEW.

**Действие:** После выбора reply вызовите `vk.method` с именем метода `"messages.send"` и словарём параметров. В словаре укажите `peer_id` со значением `message.peer_id`, `message` со значением `reply`, `random_id` со значением `vk_api.utils.get_random_id()`. Функция создаёт случайный идентификатор отправки. Не оставляйте старый тестовый вызов отправки рядом: ответ должен отправляться один раз.

**Порядок выполнения и ориентиры:** Добавьте вызов отправки на том же уровне, что reply: 8 пробелов. Параметры словаря идут внутри вызова, разделяются запятыми. Сохраните Ctrl+S, запустите в TERMINAL, введите токен и отправьте «Получится?» в браузере.

**Что должно получиться:** В диалоге VK под вопросом появился один ответ. Если отметка получения есть, а ответа нет, прочитайте ошибку отправки в TERMINAL.

**Проверка:** одно личное сообщение даёт один ответ. Для остановки нажмите Ctrl+C.

- [ ] Получилось; могу объяснить изменение.

**Где работаем:** TERMINAL VS Code и личный диалог в браузере.

**Действие:** Остановите процесс, сохраните файл и запустите заново. Снова введите токен в скрытом приглашении. Напишите три вопроса. Если бот молчит, проверьте message_new, ID, права ключа, запущенный процесс и выбранное окружение.

**Порядок выполнения и ориентиры:** Щёлкните в терминале с ботом, нажмите Ctrl+C и дождитесь PS. Сохраните bot.py, нажмите стрелку вверх до команды запуска, затем Enter. Введите ключ заново. Отправьте три сообщения по одному.

**Что должно получиться:** Каждому из трёх сообщений соответствует один ответ. Если ответы приходят дважды, проверьте другие терминалы и остановите второй экземпляр.

**Проверка:** бот отвечает после повторного запуска; ключ не оказался в исходнике.
