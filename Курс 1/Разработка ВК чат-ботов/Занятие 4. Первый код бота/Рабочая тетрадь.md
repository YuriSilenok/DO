### Шаг 3. Пишем подключение к сообществу

**Что делаем.** Дописываем в `bot.py` код подключения. Вместо `ВАШ_ТОКЕН` подставляем токен «Магического шара» из занятия 1.

```python
import vk_api
from vk_api.longpoll import VkLongPoll, VkEventType

token = "ВАШ_ТОКЕН"

vk = vk_api.VkApi(token=token)
longpoll = VkLongPoll(vk)
print("Бот запущен!")
```

**Пояснение.** Первые две строки подключают библиотеку. В переменную `token` мы кладём секретный ключ из занятия 1 — «ключ от квартиры» бота. Переменные `vk` и `longpoll` — это «проводники»: через `vk` бот будет отправлять сообщения, а через `longpoll` — узнавать о новых событиях. Строка `print("Бот запущен!")` — наш маячок: если мы её видим, значит, подключение прошло успешно.

**⚠️ Важно.** Никогда не показывайте настоящий токен в чатах.

**Проверь себя.** При запуске в терминале появилось «Бот запущен!» и нет ошибок. Остановить бота — сочетание `Ctrl + C` в терминале.

### Шаг 4. Учим бота слышать: цикл событий

**Что делаем.** Дописываем в `bot.py` главный цикл бота:

```python
for event in longpoll.listen():
    if event.type == VkEventType.MESSAGE_NEW:
        if event.to_me:
            user_text = event.text.lower()
            print("Новое сообщение:", user_text)
```

**Пояснение.** `longpoll.listen()` — это «дверь», сквозь которую к боту приходят события. Каждое новое сообщение — событие. `if event.type == VkEventType.MESSAGE_NEW` — проверяем, что событие — это именно новое сообщение (в Long Poll бывают и другие события). `if event.to_me` — проверяем, что сообщение адресовано боту, а не просто в чате. Строкой `user_text = event.text.lower()` мы запоминаем текст сообщения в переменной и приводим его к нижнему регистру. Цикл `for` — это как охранник, который следит за дверью постоянно: пришло событие — обработал, и снова ждёт.

**Проверь себя.** Напишите боту сообщение — в терминале появилось «Новое сообщение: ...».

### Шаг 5. Учим бота отвечать

**Что делаем.** Дописываем внутри цикла отправку ответа:

```python
        vk.method("messages.send", {
            "user_id": event.user_id,
            "message": "Привет! Я магический шар. Задай вопрос!",
            "random_id": 0
        })
```

**Пояснение.** `vk.method("messages.send", {...})` — это способ отправить сообщение через ВКонтакте. Внутри фигурных скобок — «анкета» сообщения: `user_id` — кому отвечать (тому, кто написал), `message` — текст ответа, `random_id` — защита от случайной двойной отправки. Сравните с обычным письмом: нужен адресат (`user_id`), текст (`message`) и уникальный номер отправления (`random_id`). Обратите внимание на отступы: код внутри `for` и внутри `if` сдвинут табуляцией или пробелами — Python так понимает, что эти строки принадлежат вложенной конструкции.

**Проверь себе.** После перезапуска бота на ваше сообщение приходит ответ от имени сообщества «Магический шар».

### Шаг 6. Переносим волшебство: случайный ответ из консоли

**Что делаем.** Переносим в `bot.py` всё «волшебное» из консольной версии: список предсказаний, импорт `random` и случайный выбор ответа вместо фиксированного приветствия.

В начало файла, к импортам, добавляем `import random`. Перед циклом объявляем список предсказаний:

```python
answers = ["Да.", "Нет.", "Спроси позже.", "Определённо да!", "Не могу сказать."]
```

А в отправке сообщения вместо фиксированного текста подставляем случайный ответ:

```python
        vk.method("messages.send", {
            "user_id": event.user_id,
            "message": random.choice(answers),
            "random_id": 0
        })
```

**Пояснение.** Мы переносим готовую логику из консольного `magic_ball.py`, ничего не переписывая с нуля: список `answers` и `random.choice(answers)` работают точно так же. Разница лишь в том, что раньше пользователь печатал вопрос в терминале, а теперь присылает сообщение во ВКонтакте. Это и есть суть профессии разработчика: один раз написал логику — и «переставляешь» её в разные места, как деталь конструктора.

**Проверь себя.** На одинаковые вопросы бот периодически отвечает по-разному; в переписке видны предсказания из списка.
