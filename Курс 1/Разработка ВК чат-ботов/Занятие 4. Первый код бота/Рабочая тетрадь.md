### Шаг 3. Пишем подключение к сообществу

**Что делаем.** Дописываем в `bot.py` код подключения. Вместо `ВАШ_ТОКЕН` указываем ключ сообщества, вместо `123456789` — числовой ID сообщества (не его короткий адрес).

```python
import vk_api
from vk_api.bot_longpoll import VkBotLongPoll, VkBotEventType

token = "ВАШ_ТОКЕН"
group_id = 123456789

vk = vk_api.VkApi(token=token, api_version="5.199")
longpoll = VkBotLongPoll(vk, group_id)
print("Бот запущен!")
```

**⚠️ Важно.** Никогда не показывайте настоящий токен в чатах.

**Проверь себя.** При запуске в терминале появилось «Бот запущен!» и нет ошибок. Остановить бота — сочетание `Ctrl + C` в терминале.

### Шаг 4. Учим бота слышать: цикл событий

**Что делаем.** Дописываем цикл обработки входящих сообщений. Событие `message_new` должно быть включено в настройках Bots Long Poll API:

```python
for event in longpoll.listen():
    if event.type == VkBotEventType.MESSAGE_NEW:
        user_id = event.message.from_id
        if user_id > 0:
            user_text = event.message.text.strip().lower()
            print("Новое сообщение:", user_text)
```

**Проверь себя.** Напишите боту сообщение — в терминале появилось «Новое сообщение: ...».

### Шаг 6. Переносим волшебство: случайный ответ из консоли

**Что делаем.** Переносим в `bot.py` всё «волшебное» из консольной версии: список предсказаний, импорт `random` и случайный выбор ответа вместо фиксированного приветствия.

В начало файла, к импортам, добавляем `import random`. Перед циклом объявляем список предсказаний:

```python
answers = ["Да.", "Нет.", "Спроси позже.", "Определённо да!", "Не могу сказать."]
```

А в отправке сообщения вместо фиксированного текста подставляем случайный ответ:

```python
            vk.method("messages.send", {
                "user_id": user_id,
                "message": random.choice(answers),
                "random_id": 0
            })
```

**Проверь себя.** На одинаковые вопросы бот периодически отвечает по-разному; в переписке видны предсказания из списка.

**Что делаем.** Проверяем, что «Оракул» полностью готов:
1) бот запускается — в терминале «Оракул запущен!» (или ваша надпись);

4) ваша вступительная фраза есть в ответе (задание 3).

**Как проверить правильность выполнения домашней работы**

Проверьте себя по чек-листу — работа выполнена верна, если выполняется **всё** из списка:

1. **Бот запускается.** В терминале видно ваше сообщение о запуске, а в переписке приходит ответ.
2. **Ответ — ваш.** Бот отвечает текстом из вашего варианта, а не примером из класса.
3. **Случайность работает.** На одинаковый вопрос ответы периодически разные.
4. **Ошибка записана.** В задании 4 записан текст ошибки.
5. **Обработка сообщения работает.** Бот получает событие `message_new` и отправляет ответ вызовом `messages.send`.
6. **Безопасность.** Токен «Оракула» нигде не показан.
