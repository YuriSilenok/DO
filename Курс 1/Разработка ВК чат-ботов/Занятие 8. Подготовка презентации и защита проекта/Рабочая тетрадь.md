## Как выполнять действия в VS Code

1. Откройте **File → Open Folder / Файл → Открыть папку** и выберите свою папку `vk_bot`. Слева в **Explorer / Проводник** (`Ctrl+Shift+E`) находятся файлы, в центре — редактор выбранного файла. Файлы `.py` создавайте в корне `vk_bot`, не внутри `.venv`.
2. Код Python вводите в центральный редактор файла `.py`, затем нажимайте `Ctrl+S`. Точка на вкладке означает несохранённые изменения. Фрагменты SQL помещайте в кавычках в аргументы `execute` в Python-файле; их не вводят как команды PowerShell.
3. Команды установки и запуска вводите внизу: **Terminal → New Terminal / Терминал → Создать терминал**. В этой тетради для Windows используется **PowerShell**. Щёлкните после приглашения `PS …>`, наберите команду без самого приглашения и нажмите `Enter`. Панели **Output / Вывод** и **Debug Console / Консоль отладки** для этих команд не подходят.
4. Проверьте текущую папку командой `Get-Location`: путь должен оканчиваться на `vk_bot`. Командой `Get-ChildItem` посмотрите файлы: нужный `.py` и папка `.venv` должны быть здесь. Если папка другая, откройте правильную через File → Open Folder и создайте новый терминал. Если видите `>>>`, открыт интерактивный Python: введите `exit()` и Enter, чтобы вернуться к PowerShell.
5. После создания окружения запускайте нужный файл командой из блока ниже. Начальное `.\` означает «из текущей папки». Если PowerShell активировал среду автоматически, прямой путь всё равно подходит. Если `.venv` ещё нет, сначала выполните создание среды из занятия 2.

```powershell
.\.venv\Scripts\python.exe bot.py
```

6. Пока бот работает, приглашение `PS …>` не возвращается: терминал занят программой. Вопросы и команды боту отправляйте в **диалоге с сообществом VK**. Консольной программе ответ на `input` вводите в том же TERMINAL после её вопроса. Ключ вводится только после приглашения `Токен сообщества:`; символы `getpass` не отображаются.
7. Перед новой правкой щёлкните в TERMINAL и нажмите `Ctrl+C`, дождитесь приглашения PowerShell. Исправьте файл, сохраните `Ctrl+S`, снова выполните команду запуска. Работающая программа не подхватывает сохранённые изменения сама. Ошибки Python читаем в TERMINAL: последняя строка — тип и описание, выше — файл и номер строки. Кнопка Problems / Проблемы помогает найти синтаксические замечания, но не заменяет запуск.

## Классная работа

### Шаг 1. Собираем проверку

**Где работаем:** VS Code → новый файл checks.md рядом с bot.py; браузер с VK.

**Действие:** Составьте таблицу: действие → ожидаемый ответ → фактический ответ. Включите начало, помощь, правила, вопрос, неизвестный текст и кнопку. Выполните сценарии и исправьте найденные ошибки до подготовки слайдов.

**Порядок выполнения и ориентиры:** В checks.md запишите для каждой проверки действие и ожидаемый результат, затем запустите bot.py в TERMINAL. Отправляйте команды в VK и дописывайте фактические ответы в checks.md. Markdown — обычный текст, запускать его Python не нужно.

**Что должно получиться:** У каждого сценария есть ожидание и наблюдение; несоответствие отмечено, а не скрыто.

**Проверка:** в таблице шесть проверок и нет необъяснённых ошибок.

### Шаг 2. Готовим пять слайдов

**Где работаем:** Программа для презентаций; bot.py остаётся открыт в VS Code.

**Действие:** Создайте слайды: идея игры; возможности; устройство; демонстрация; итоги. На первом укажите автора. На слайде устройства нарисуйте путь: сообщение → Bots Long Poll → условия → random.choice → messages.send. Случайный ответ не означает понимание вопроса.

**Порядок выполнения и ориентиры:** Создайте пять слайдов по плану. Для схемы посмотрите реальные участки bot.py: longpoll, цепочку условий, выбор и отправку. На слайд перенесите названия действий, а не полный код.

**Что должно получиться:** Каждый блок схемы можете найти в своём bot.py через Ctrl+F.

**Проверка:** вы можете объяснить каждый блок своими словами.

### Шаг 3. Выбираем примеры

**Где работаем:** Личный диалог VK и слайд демонстрации.

**Действие:** Покажите вопрос, предсказание и кнопку. Можно использовать обезличенный фрагмент своего диалога. Не включайте токен, ввод getpass или личные сообщения. Запасной сценарий при отсутствии сети — таблица тестов и объяснение кода.

**Порядок выполнения и ориентиры:** Выберите только фрагмент своего учебного диалога. Перед показом проверьте, что в кадре нет чужой переписки или окна с ключом. Запишите запасной сценарий в checks.md.

**Что должно получиться:** На примере видно действие пользователя и соответствующий ответ бота.

**Проверка:** в презентации только реальные возможности.
