### Шаг 2. Пишем UPDATE

Добавьте функцию feed_pet(conn, owner_id) до подключения. Внутри создайте курсор. Составьте запрос UPDATE pets SET satiety = MIN(100, satiety + 20) WHERE owner_id = ? AND satiety < 100. Выполните с параметром owner_id, затем commit. Верните cur.rowcount. WHERE обязателен: без него поменяются все питомцы. MIN здесь сравнивает два числа в SQLite.

**Проверка:** изменяется только строка владельца; функция возвращает 1 при изменении или 0, если подходящей строки нет.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Добавляем команду

Перед else добавьте ветку «кормить». Сначала get_pet: если None — приглашение приютить. Иначе вызовите feed_pet, затем снова get_pet, чтобы получить актуальную сытость. По числу изменённых строк выберите сообщение об успехе либо полном насыщении. Вызов messages.send остаётся общим.

**Проверка:** после первого кормления сытость 70, затем 90, затем 100, затем 100.
