### Шаг 2. Добавляем команду «Начать»

**Что делаем.** Внутри цикла, перед случайным ответом, добавляем проверку команды:

```python
if user_text == "начать":
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": "Привет! Я магический шар. Задай мне вопрос — и я отвечу!",
        "random_id": 0
    })
```

**Пояснение.** `user_text` — это текст сообщения, приведённый к нижнему регистру (мы сделали это на занятии 4). Поэтому команда сработает и на «Начать», и на «НАЧАТЬ», и на «НаЧатЬ»: регистр больше не важен. Сравните с замком: `.lower()` ровняет все «ключи» (слова) к одному виду, чтобы любой вариант подошёл к замку. Названия команд обычно пишут строчными буквами и сравнивают через `==`.

**Проверь себя.** Сообщение «Начать» вызывает приветствие бота.

### Шаг 3. Добавляем команду «Помощь»

**Что делаем.** Добавляем вторую команду — «Помощь», которая покажет список того, что бот умеет:

```python
elif user_text == "помощь":
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": "Напиши мне любой вопрос — я дам ответ! Команды: «Начать», «Помощь».",
        "random_id": 0
    })
```

**Пояснение.** Команды добавляются по очереди: `if` — первая, `elif` — вторая. Так можно навесить хоть десять команд: каждая следующая проверяется только в том случае, если предыдущие не совпали. Порядок проверок не критичен, но удобно держать «Помощь» среди последних — она описывает весь список, и её текст придётся обновлять по мере роста бота.

**Проверь себя.** Сообщение «Помощь» вызывает список команд.

### Шаг 4. Добавляем ответ по умолчанию: «вытягиваем предсказание»

**Что делаем.** После всех команд добавляем ветку `else`, которая срабатывает, когда сообщение не совпало ни с одной командой. В неё переносим случайный ответ «Магического шара»:

```python
else:
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": random.choice(answers),
        "random_id": 0
    })
```

**Пояснение.** Ветка `else` — «ловушка для всего остального». Любое сообщение, которое не является командой, бот воспринимает как вопрос и отвечает случайным предсказанием. Это и есть основная «рабочая» логика «Магического шара». Сравните с игрой: если игрок не зовёт на помощь и не начинает заново — он просто играет.

**Проверь себе.** На «Привет», «Стоит ли идти гулять?», «Когда выйдет новая серия?» бот отвечает предсказаниями.

### Шаг 5. Знакомимся с f-строками

**Что делаем.** Добавляем команду «Кто я», которая отвечает именем пользователя. Имя запрашиваем через API ВКонтакте:

```python
elif user_text == "кто я":
    user_info = vk.method("users.get", {"user_ids": event.user_id})
    first_name = user_info[0]["first_name"]
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": f"Ты — {first_name}!",
        "random_id": 0
    })
```

**Пояснение.** f-строка (буква `f` перед кавычкой) позволяет вставлять значения переменных прямо в текст через фигурные скобки `{}`. Вместо `{first_name}` подставится реальное имя пользователя. Сравните два способа: склеивание через `+` — «Ты — " + first_name + "!» (длинно и легко ошибиться), а f-строка — как шаблон с окошками: `f"Ты — {first_name}!"`. `vk.method("users.get", ...)` запрашивает данные пользователя, а `[0]["first_name"]` берёт имя первого (и единственного) пользователя в ответе.

**Проверь себя.** Команда «Кто я» отвечает вашему имени.
