## Классная работа

### Шаг 1. Находим место изменения

Остановите процесс. Найдите присваивание reply внутри MESSAGE_NEW и единственный вызов messages.send. Сейчас меняем только вычисление reply; отправку оставляем после всей цепочки условий на том же уровне отступа, что и её первый if.

**Проверка:** можете показать подготовку, обработку и отправку.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Добавляем приветствие

Замените безусловное присваивание reply условием `if user_text == "начать":`. В теле присвойте reply своё приветствие и приглашение задать вопрос. В конце цепочки пока добавьте else со случайным ответом.

**Проверка:** «Начать» даёт приветствие и не вызывает второго ответа.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Добавляем помощь и представление

Между первым if и последним else добавьте две ветки elif: для «помощь» с описанием команд и для «кто ты» с представлением шара. Каждая ветка только задаёт reply. Новые условия нельзя дописывать после else.

**Проверка:** все три команды возвращают разные осмысленные ответы.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Распознаём вопрос

Перед финальным else добавьте ветку для пустого user_text с просьбой прислать текст. Затем ветку с `user_text.endswith("?")` и случайным ответом. Последний else теперь предлагает написать вопрос со знаком вопроса. Удалите прежний случайный ответ из else. Это правило нашего интерфейса, а не понимание смысла текста.

**Проверка:** текст без ? даёт подсказку, вопрос с ? — предсказание; стикер без текста не ломает бота.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Используем f-строку

Добавьте до else команду «мой номер». Для неё сформируйте reply как f-строку с user_id в фигурных скобках. Это числовой ID, а не имя человека. Дополнительный вызов users.get для этого не нужен.

**Проверка:** команда выводит ID отправителя.

- [ ] Получилось; могу объяснить изменение.

### Шаг 6. Проверяем ветки

Запустите бота. Протестируйте « НАЧАТЬ », «помощь», «кто ты», «мой номер», «Получится?», «абракадабра», вложение без текста. Нормализация происходит до условий; для каждого случая reply присвоен.

**Проверка:** семь сценариев проходят, двойных ответов нет.

- [ ] Получилось; могу объяснить изменение.
