### Шаг 3. Знакомимся с типами данных

**Что делаем.** Дописываем в `magic_ball.py` код, в котором хранятся значения разных типов, и запускаем:

```python
name = "Шар"          # str — строка (текст)
age = 15              # int — целое число
height = 1.65         # float — число с плавающей точкой
is_magic = True       # bool — истина (True) или ложь (False)
print(name, age, height, is_magic)
```

**Пояснение.** Python различает виды данных: текст — `str`, целые числа — `int`, дробные — `float`, а `bool` принимает только `True` или `False`. Важно, чтобы кавычки вокруг текста стояли всегда: без них Python решит, что это переменная, и выдаст ошибку — как если в разговоре вы скажете слово, которого собеседник не знает, и он переспросит.

**Проверь себя.** В терминале видны значения всех четырёх переменных, разделённые пробелами.

### Шаг 4. Учимся задавать вопрос: ввод текста

**Что делаем.** Пишем программу, в которой спрашиваем у пользователя вопрос и выводим его на экран:

### Шаг 5. Учимся «выбирать случайно»: знакомство с random

**Что делаем.** Добавляем в начало файла подключение модуля случайности, а в конце — выбор предсказания из списка:

```python
import random

answers = ["Да.", "Нет.", "Спроси позже.", "Определённо да!", "Не могу сказать."]
print("Магический шар отвечает:", random.choice(answers))
```

**Пояснение.** `import random` подключает готовый «чемоданчик» со случайными функциями — как подключение дополнительной библиотеки инструментов. `answers` — список (перечень) предсказаний в квадратных скобках. `random.choice(answers)` выбирает из списка один случайный элемент — как жребий. Именно случайность делает «Магический шар» «магическим»: ответ нельзя предугадать.

**⚠️ Важно.** `import random` должен стоять в самом верху файла — до использования `random.choice`. Порядок в коде важен: сначала подключаем инструмент, потом пользуемся им.

**Проверь себя.** При каждом запуске «Шар» отвечает, и за несколько запусков ответы разные.

### Шаг 6. Учимся ветвить логику: условия if/else

**Что делаем.** После вывода предсказания добавляем проверку на «необычный вопрос»:

```python
if user_question == "кто ты":
    print("Я магический шар! Спрашивай, я всё знаю.")
else:
    print("Хм, интересный вопрос. Мой ответ тебя удивит!")
```

**Пояснение.** Программа сравнивает текст, который ввёл пользователь, с образцом `"кто ты"`. Если совпало — выполняется первая ветка, иначе — вторая. Сравните с расписанием: «Если сегодня среда — идём на информатику, иначе — на математику». Здесь важно, что `input` возвращает текст с клавиатуры с учётом регистра: чтобы команда работала и для «Кто ты», и для «КТО ТЫ», текст обычно приводят к нижнему регистру через `.lower()` — попробуйте добавить эту команду.

**Проверь себя.** Вопрос «кто ты» даёт один ответ, любой другой вопрос — второй.

**Как проверить правильность выполнения домашней работы**
