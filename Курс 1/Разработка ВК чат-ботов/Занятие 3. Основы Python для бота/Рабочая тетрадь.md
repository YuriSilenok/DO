### Шаг 5. Учимся «выбирать случайно»: знакомство с random

**Что делаем.** Добавляем в начало файла подключение модуля случайности, а в конце — выбор предсказания из списка:

```python
import random

answers = ["Да.", "Нет.", "Спроси позже.", "Определённо да!", "Не могу сказать."]
print("Магический шар отвечает:", random.choice(answers))
```

**⚠️ Важно.** `import random` должен стоять в самом верху файла — до использования `random.choice`. Порядок в коде важен: сначала подключаем инструмент, потом пользуемся им.

**Проверь себя.** При каждом запуске «Шар» отвечает, и за несколько запусков ответы разные.

### Шаг 6. Учимся ветвить логику: условия if/else

**Что делаем.** Заменяем строку вывода предсказания условием: нормализуем введённый на шаге 4 текст и выводим специальный ответ для `кто ты`, а для остальных вопросов — случайное предсказание.

```python

if user_question == "кто ты":

else:
    print("Магический шар отвечает:", random.choice(answers))
```

### Задание 5. Итоговая проверка

**Что делаем.** Прогоняем `oracle.py` и проверяем:
1) «Оракул» приветствует и задаёт вопрос;
2) на обычный вопрос отвечает случайно из вашего списка;
3) на ваши «особые вопросы» отвечает специально;
4) при нескольких запусках ответы разные (случайные).

**Как проверить правильность выполнения домашней работы**

Проверьте себя по чек-листу — работа выполнена верно, если выполняется **всё** из списка:

1. **Переменные есть.** В `oracle.py` созданы переменные разных типов: текст, число, а при желании — True/False.
2. **Ввод работает.** `input(...)` получает вопрос пользователя, и программа его печатает.
3. **Случайность работает.** `random.choice(answers)` выбирает ответ из вашего списка.
4. **Условие работает.** На ваши особые вопросы ответы специальные, на остальные — случайные.

**Если какой-то пункт не выполняется** — перечитайте соответствующий шаг классной работы, исправьте код и запустите программу снова.
