## Как выполнять действия в VS Code

1. Откройте **File → Open Folder / Файл → Открыть папку** и выберите свою папку `vk_bot`. Слева в **Explorer / Проводник** (`Ctrl+Shift+E`) находятся файлы, в центре — редактор выбранного файла. Файлы `.py` создавайте в корне `vk_bot`, не внутри `.venv`.
2. Код Python вводите в центральный редактор файла `.py`, затем нажимайте `Ctrl+S`. Точка на вкладке означает несохранённые изменения. Фрагменты SQL помещайте в кавычках в аргументы `execute` в Python-файле; их не вводят как команды PowerShell.
3. Команды установки и запуска вводите внизу: **Terminal → New Terminal / Терминал → Создать терминал**. В этой тетради для Windows используется **PowerShell**. Щёлкните после приглашения `PS …>`, наберите команду без самого приглашения и нажмите `Enter`. Панели **Output / Вывод** и **Debug Console / Консоль отладки** для этих команд не подходят.
4. Проверьте текущую папку командой `Get-Location`: путь должен оканчиваться на `vk_bot`. Командой `Get-ChildItem` посмотрите файлы: нужный `.py` и папка `.venv` должны быть здесь. Если папка другая, откройте правильную через File → Open Folder и создайте новый терминал. Если видите `>>>`, открыт интерактивный Python: введите `exit()` и Enter, чтобы вернуться к PowerShell.
5. После создания окружения запускайте нужный файл командой из блока ниже. Начальное `.\` означает «из текущей папки». Если PowerShell активировал среду автоматически, прямой путь всё равно подходит. Если `.venv` ещё нет, сначала выполните создание среды из занятия 2.

```powershell
.\.venv\Scripts\python.exe magic_ball.py
```

6. Пока бот работает, приглашение `PS …>` не возвращается: терминал занят программой. Вопросы и команды боту отправляйте в **диалоге с сообществом VK**. Консольной программе ответ на `input` вводите в том же TERMINAL после её вопроса. Ключ вводится только после приглашения `Токен сообщества:`; символы `getpass` не отображаются.
7. Перед новой правкой щёлкните в TERMINAL и нажмите `Ctrl+C`, дождитесь приглашения PowerShell. Исправьте файл, сохраните `Ctrl+S`, снова выполните команду запуска. Работающая программа не подхватывает сохранённые изменения сама. Ошибки Python читаем в TERMINAL: последняя строка — тип и описание, выше — файл и номер строки. Кнопка Problems / Проблемы помогает найти синтаксические замечания, но не заменяет запуск.

## Классная работа

### Шаг 1. Называем значения

**Где работаем:** VS Code → Explorer → новый файл magic_ball.py.

**Действие:** В начале `magic_ball.py` создайте переменную `name` со строкой — именем шара, а затем выведите её через `print`. Присваивание использует один знак `=`, сравнение — два. На черновике проверьте `type(name)`, `type(5)`, `type(True)`: это строка, целое число и логическое значение.

**Порядок выполнения и ориентиры:** Создайте файл рядом с first.py, вне папки .venv. Введите переменную и вывод в центральной вкладке, сохраните. В TERMINAL выполните `.\.venv\Scripts\python.exe magic_ball.py.` Для опытов с type добавьте временные вызовы print в этот же файл и затем удалите их.

**Что должно получиться:** В терминале видно имя шара, а при опыте с типами — str, int, bool. После проверки в файле остаются только нужные строки проекта.

**Проверка:** объясняете, почему имя в кавычках, а число — без них.

### Шаг 2. Получаем вопрос

**Где работаем:** Редактор magic_ball.py, после приветствия.

**Действие:** После приветствия вызовите `input` с приглашением задать вопрос. Сохраните возвращённую строку в `user_question`. Временно выведите её, затем уберите этот отладочный вывод.

**Порядок выполнения и ориентиры:** Добавьте присваивание результата input переменной user_question. Сохраните, запустите файл. Когда в TERMINAL появится приглашение задать вопрос, щёлкните в терминале, напечатайте вопрос и нажмите Enter.

**Что должно получиться:** До Enter программа ждёт, после Enter виден ваш текст. Вопрос вводится в терминал запущенной программы, а не новой строкой в Python-файл.

**Проверка:** при запуске программа ждёт ввода.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Создаём набор ответов

**Где работаем:** Редактор magic_ball.py: импорт в первой строке, список перед input.

**Действие:** До ввода вопроса создайте `answers`: список из пяти придуманных коротких предсказаний. Список записывают в квадратных скобках, строки разделяют запятыми. В первой строке файла подключите модуль выражением `import random`.

**Порядок выполнения и ориентиры:** Щёлкните в начало файла и добавьте импорт. Ниже переменной имени, но до вопроса, создайте список answers. Разделяйте строки запятыми, закройте квадратную скобку. Сохраните файл.

**Что должно получиться:** После запуска приглашение input по-прежнему появляется без SyntaxError. Список содержит пять отдельных строк, а не одну длинную строку.

**Проверка:** список не пуст; каждый элемент — отдельная строка.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Выбираем ответ

**Где работаем:** Редактор magic_ball.py: после получения вопроса; затем TERMINAL.

**Действие:** После ввода получите один элемент через `random.choice(answers)` и выведите результат. Запускайте `.venv\Scripts\python.exe magic_ball.py`. Повторы допустимы: случайность не обещает новый ответ на каждом запуске.

**Порядок выполнения и ориентиры:** Добавьте выбор и вывод предсказания после input. Сохраните и запустите программу несколько раз: стрелка вверх в терминале повторяет команду запуска. При каждом запуске введите вопрос и Enter.

**Что должно получиться:** На каждый запуск приходит один ответ из answers; одинаковые ответы подряд допустимы.

**Проверка:** все выпавшие ответы есть в списке; отсутствие разнообразия за пару запусков не считается ошибкой.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Разделяем случаи

**Где работаем:** Редактор magic_ball.py: вместо прежнего безусловного вывода ответа.

**Действие:** После input создайте нормализованный текст: примените к вопросу `.strip().lower()` и сохраните в `user_text`. Замените прежний безусловный вывод цепочкой: `if` для пустого текста — просьба задать вопрос; `elif` для «кто ты» — представление; `else` — случайное предсказание. Условия заканчиваются двоеточием; тело ветки имеет отступ 4 пробела.

**Порядок выполнения и ориентиры:** Найдите строку с random.choice через Ctrl+F. Замените её вывод цепочкой условий, а не добавляйте вторую цепочку ниже старого вывода. Нормализацию разместите после input. Внизу справа настройте Spaces: 4; Tab внутри ветки добавит отступ.

**Что должно получиться:** Три отдельных запуска: Enter без текста → просьба задать вопрос; « КТО ТЫ » → представление; «Получится?» → одно предсказание.

**Проверка:** пустая строка, «КТО ТЫ» с пробелами и обычный вопрос дают три нужных типа ответа.

- [ ] Получилось; могу объяснить изменение.
