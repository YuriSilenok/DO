## Классная работа

### Шаг 1. Называем значения

В начале `magic_ball.py` создайте переменную `name` со строкой — именем шара, а затем выведите её через `print`. Присваивание использует один знак `=`, сравнение — два. На черновике проверьте `type(name)`, `type(5)`, `type(True)`: это строка, целое число и логическое значение.

**Проверка:** объясняете, почему имя в кавычках, а число — без них.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Получаем вопрос

После приветствия вызовите `input` с приглашением задать вопрос. Сохраните возвращённую строку в `user_question`. Временно выведите её, затем уберите этот отладочный вывод.

**Проверка:** при запуске программа ждёт ввода.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Создаём набор ответов

До ввода вопроса создайте `answers`: список из пяти придуманных коротких предсказаний. Список записывают в квадратных скобках, строки разделяют запятыми. В первой строке файла подключите модуль выражением `import random`.

**Проверка:** список не пуст; каждый элемент — отдельная строка.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Выбираем ответ

После ввода получите один элемент через `random.choice(answers)` и выведите результат. Запускайте `.venv\Scripts\python.exe magic_ball.py`. Повторы допустимы: случайность не обещает новый ответ на каждом запуске.

**Проверка:** все выпавшие ответы есть в списке; отсутствие разнообразия за пару запусков не считается ошибкой.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Разделяем случаи

После input создайте нормализованный текст: примените к вопросу `.strip().lower()` и сохраните в `user_text`. Замените прежний безусловный вывод цепочкой: `if` для пустого текста — просьба задать вопрос; `elif` для «кто ты» — представление; `else` — случайное предсказание. Условия заканчиваются двоеточием; тело ветки имеет отступ 4 пробела.

**Проверка:** пустая строка, «КТО ТЫ» с пробелами и обычный вопрос дают три нужных типа ответа.

- [ ] Получилось; могу объяснить изменение.
