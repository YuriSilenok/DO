# Иллюстрации к рабочей тетради (для преподавателя)

Этот файл — инструкция для **преподавателя**. Ученик не вставляет скриншоты сам: иллюстрации готовит преподаватель **до раздачи тетрадей**. В тексте тетради для ученика про скриншоты **не упоминается** — картинки уже стоят в нужных местах как готовый материал.

**Как подготовить.**

1. Выполните занятие сами или используйте образец экрана.
2. Сохраните скриншоты в эту папку (`images`) с именами из таблицы ниже.
3. Проверьте, что все файлы лежат на своих местах — изображения уже подставлены в тетрадь.

| Рис. 1 | Скачивание Python с официального сайта | `shag-01-python-site.png` |
| Рис. 2 | Установка Python Install Manager | `shag-02-install-python.png` |
