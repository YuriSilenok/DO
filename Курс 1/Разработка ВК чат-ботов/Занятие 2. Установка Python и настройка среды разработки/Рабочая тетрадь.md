## Классная работа

### Шаг 1. Устанавливаем Python

Скачайте Python Install Manager с [python.org](https://www.python.org/downloads/). Установите стабильную версию Python по подсказкам менеджера. Откройте новый терминал и выполните `py --version`. Если Python уже установлен и команда показывает Python 3, повторная установка не нужна.

**Проверка:** запишите фактическую версию: __________.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Устанавливаем редактор

Установите [VS Code](https://code.visualstudio.com/) и расширение Python от Microsoft. Создайте папку `vk_bot` и откройте её через File → Open Folder.

**Проверка:** видите папку проекта в проводнике VS Code.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Отделяем зависимости

В терминале VS Code из папки проекта выполните `py -m venv .venv`. В палитре команд выберите Python: Select Interpreter и интерпретатор `.venv`. Окружение — отдельный набор библиотек для проекта. В следующих командах Windows используем прямой путь к нему: активация PowerShell не требуется.

**Проверка:** команда `.venv\Scripts\python.exe --version` выводит версию.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Пишем первую строку

Создайте `first.py`. Вызовите `print` с собственной фразой приветствия «Магического шара»: текст поместите в кавычки внутри круглых скобок. Сохраните файл. Запустите `.venv\Scripts\python.exe first.py`.

**Проверка:** терминал вывел вашу фразу один раз.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Находим ошибку

Временно уберите закрывающую кавычку, сохраните и запустите файл. Найдите имя файла, строку и описание SyntaxError. Верните кавычку и повторите запуск. Если команда открывает магазин или не найдена, проверьте установку Python и путь к окружению.

**Проверка:** можете показать, где читать сообщение об ошибке.

- [ ] Получилось; могу объяснить изменение.
