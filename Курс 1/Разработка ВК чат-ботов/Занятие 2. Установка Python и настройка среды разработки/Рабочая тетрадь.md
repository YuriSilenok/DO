# Часть 1. Классная работа

### Шаг 1. Скачиваем Python

**Что делаем.** Открываем официальный сайт python.org и скачиваем установщик для своей системы (кнопка «Download Python 3.x.x»).

**Пояснение.** Python — это язык программирования, на котором мы напишем бота «Магический шар». Представьте, что язык — это «разговорный язык», понятный компьютеру: мы пишем на нём инструкции, а компьютер их выполняет. Всегда устанавливаем только официальную последнюю версию с сайта python.org. Скачивать Python с посторонних сайтов нельзя — там могут быть вредоносные программы, как в подозрительных «бесплатных» установщиках.

**Проверь себя.** В папке «Загрузки» появился файл `python-3.x.x.exe` (имя может отличаться цифрами версии).

### Шаг 2. Устанавливаем Python

**Что делаем.** Запускаем скачанный установщик, ставим **обязательную галочку «Add Python to PATH»** и жмём «Install Now».

**Пояснение.** Галочка PATH — самая важная на этом экране. PATH — это «список адресов», по которым Windows ищет программы: если отметить галочку, Windows будет знать, где лежит Python, и команду `python` можно запускать из любой папки. Без галочки компьютер будет отвечать «не знаю такой команды» — как человек, который не знает адреса вашего дома. После установки окно закроется — значит, всё прошло успешно.

**Проверь себя.** Установка завершилась без ошибок, окно мастера закрылось.

![Рис. 2. Установка Python: галочка «Add Python to PATH».](images/shag-02-install-python.png)

### Шаг 3. Проверяем установку Python

**Что делаем.** В командной строке (терминале) вводим команду `python --version` и проверяем, что в ответ видим номер версии (например, `Python 3.12.4`).

**Пояснение.** Команда `python --version` — способ убедиться, что Python действительно установлен и виден системе. Это как проверить, работает ли только что купленный телефон: звоним на него — и слышим ответ. Если вместо номера версии появляется ошибка «не является внутренней или внешней командой» — значит, галочка PATH на шаге 2 не была отмечена, и установку нужно повторить.

**💡 Вариативность (классная работа).** На некоторых компьютерах вместо `python` работает команда `py`. Если `python --version` не сработала — пробуем `py --version` (сделайте пометку, какая команда работает у вас).

**Проверь себя.** В ответ — строка вида `Python 3.x.x` без ошибок.

### Шаг 4. Устанавливаем Visual Studio Code

**Что делаем.** Скачиваем редактор кода Visual Studio Code с официального сайта code.visualstudio.com и устанавливаем его. После установки открываем VS Code и устанавливаем расширение Python от Microsoft (вкладка «Extensions», поиск по слову `python`).

**Пояснение.** VS Code — редактор, в котором мы будем писать код. Сравните обычный «Блокнот» и VS Code: в блокноте можно печатать, но он не подскажет ошибку и не подсветит код цветом. VS Code умеет подсвечивать команды, подсказывать и запускать программы кнопкой — это как «умный Блокнот» для программиста. Расширение Python добавляет в редактор понимание языка: подсветку, подсказки и кнопку запуска.

**Проверь себя.** VS Code открывается, а во вкладке «Extensions» установлено расширение Python от Microsoft (без кнопки «Install»).

### Шаг 5. Создаём папку проекта и файл первой программы

**Что делаем.** Создаём на компьютере папку проекта. Имя — только латиницей и без пробелов, например `vk_bot` (можно выбрать своё). В VS Code открываем эту папку (Файл → Открыть папку) и создаём в ней файл `first.py` с таким кодом:

```python
print("Привет, мир!")
```

После этого запускаем программу — в VS Code для этого есть кнопка «Запуск» (треугольник справа сверху) или команда `python first.py` в терминале.

**Пояснение.** Папка проекта — это «квартира» всех наших файлов: кода, картинок, заметок. Имя латиницей и без пробелов важно, потому что программы и команды надёжнее работают с простыми именами: пробелы и кириллица иногда «ломают» пути. Файл `first.py` — наша первая программа: `print(...)` — команда «покажи на экране». Расширение `.py` говорит компьютеру, что внутри — код на Python.

**Проверь себя.** В терминале появилась строка `Привет, мир!`.

### Задание 6. Итоговая проверка

**Что делаем.** Проверяем, что домашняя среда полностью готова к следующему занятию:
1) Python работает в терминале (`python --version` или `py --version`);
2) VS Code открыт в папке проекта, расширение Python установлено;
3) файл с вашими фразами запускается, в терминале видны все строки.

**Как проверить правильность выполнения домашней работы**

Проверьте себя по чек-листу — работа выполнена верна, если выполняется **всё** из списка:

1. **Python установлен.** `python --version` (или `py --version`) показывает номер версии без ошибок.
2. **Среда открыта.** VS Code открыт в папке проекта, расширение Python установлено от Microsoft.
3. **Программа запускается.** Файл с фразами «Оракула» существует, а в терминале видны все строки по одной на строке.
4. **Ответы верные.** PATH нужен, чтобы команда `python` работала из любой папки; `python --version` показывает версию Python; латиница и отсутствие пробелов нужны, чтобы папку без проблем находили программы и команды.
