## О занятии

**Цели занятия**

1. Скачать и установить Python — язык, на котором будет работать бот.
2. Убедиться, что Python запускается из командной строки.
3. Установить редактор кода Visual Studio Code и расширение для Python.
4. Создать папку проекта и запустить первую программу.

**Что понадобится**

- Компьютер под управлением Windows 10 или новее с доступом в интернет и браузером.
- Разрешение преподавателя на установку программ.
- Аккаунт ВКонтакте с прошлого занятия сегодня не нужен — он понадобится в следующий раз.

**Как работать с тетрадью**

- **Классная работа** — выполняйте шаги вместе с преподавателем.
- **Домашняя работа** — выполните задания самостоятельно.

# Часть 1. Классная работа

### Шаг 1. Скачиваем Python

**Что делаем.** Открываем [официальную страницу загрузки Python](https://www.python.org/downloads/) и скачиваем Python Install Manager для Windows.

**Проверь себя.** Python Install Manager скачан с python.org.

![Рис. 1. Скачивание Python с официального сайта.](images/shag-01-python-site.png)

*Рис. 1. Скачивание Python с официального сайта.*

- [ ] шаг выполнен

---

### Шаг 2. Устанавливаем Python

**Что делаем.** Запускаем Python Install Manager и устанавливаем последнюю стабильную версию Python по инструкции установщика. Если установщик предлагает добавить каталог команд в `PATH`, включите эту настройку; запуск также доступен командой `py`.

**Проверь себя.** Установлены Python и команды `python` и `py`.

![Рис. 2. Установка Python Install Manager.](images/shag-02-install-python.png)

*Рис. 2. Установка Python Install Manager.*

- [ ] шаг выполнен

---

### Шаг 3. Проверяем установку Python

**Что делаем.** Открываем новый терминал и выполняем `py --version` или `python --version`.

**💡 Вариативность (классная работа).** Если команда не найдена, закройте и снова откройте терминал. Если проблема осталась, выполните установку Python Install Manager по официальной документации Python.

**Проверь себя.** Команда показывает номер версии Python без ошибки.

![Рис. 3. Вывод команды python --version в терминале.](images/shag-03-version.png)

*Рис. 3. Вывод команды python --version в терминале.*

- [ ] шаг выполнен

---

### Шаг 4. Устанавливаем Visual Studio Code

**Что делаем.** Скачиваем и устанавливаем [Visual Studio Code](https://code.visualstudio.com/). В разделе **Extensions** устанавливаем расширение **Python** от Microsoft.

**Проверь себя.** VS Code открывается, а во вкладке «Extensions» установлено расширение Python от Microsoft (без кнопки «Install»).

![Рис. 4. VS Code с установленным расширением Python.](images/shag-04-vscode.png)

*Рис. 4. VS Code с установленным расширением Python.*

- [ ] шаг выполнен

---

### Шаг 5. Создаём папку проекта и файл первой программы

**Что делаем.** Создаём папку проекта `vk_bot` и открываем её в VS Code (**File → Open Folder**). В папке создаём файл `first.py`:

```python
print("Привет, мир!")
```

В VS Code выполняем команду **Python: Select Interpreter**, выбираем установленную версию Python и запускаем файл кнопкой **Run Python File** или командой `py first.py` в терминале.

**Проверь себя.** В терминале появилась строка `Привет, мир!`.

![Рис. 5. Папка проекта и первая программа.](images/shag-05-first.png)

*Рис. 5. Папка проекта и первая программа.*

### Задание 6. Итоговая проверка

**Что делаем.** Проверяем, что домашняя среда полностью готова к следующему занятию:
1) Python работает в терминале (`python --version` или `py --version`);
2) VS Code открыт в папке проекта, расширение Python установлено;
3) файл с вашими фразами запускается, в терминале видны все строки.

**Как проверить правильность выполнения домашней работы**

Проверьте себя по чек-листу — работа выполнена верна, если выполняется **всё** из списка:

1. **Python установлен.** `py --version` или `python --version` показывает номер версии без ошибок.
2. **Среда открыта.** VS Code открыт в папке проекта, расширение Python установлено от Microsoft.
3. **Программа запускается.** Файл с фразами «Оракула» существует, а в терминале видны все строки по одной на строке.

**Если какой-то пункт не выполняется** — повторите соответствующий шаг классной работы, перепроверьте себя.

Если всё выполнено — среда готова, и на следующем занятии мы начнём программировать по-настоящему: напишем консольную версию «Магического шара».
