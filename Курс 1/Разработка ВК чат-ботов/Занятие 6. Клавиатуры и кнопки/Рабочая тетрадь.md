## Как выполнять действия в VS Code

1. Откройте **File → Open Folder / Файл → Открыть папку** и выберите свою папку `vk_bot`. Слева в **Explorer / Проводник** (`Ctrl+Shift+E`) находятся файлы, в центре — редактор выбранного файла. Файлы `.py` создавайте в корне `vk_bot`, не внутри `.venv`.
2. Код Python вводите в центральный редактор файла `.py`, затем нажимайте `Ctrl+S`. Точка на вкладке означает несохранённые изменения. Фрагменты SQL помещайте в кавычках в аргументы `execute` в Python-файле; их не вводят как команды PowerShell.
3. Команды установки и запуска вводите внизу: **Terminal → New Terminal / Терминал → Создать терминал**. В этой тетради для Windows используется **PowerShell**. Щёлкните после приглашения `PS …>`, наберите команду без самого приглашения и нажмите `Enter`. Панели **Output / Вывод** и **Debug Console / Консоль отладки** для этих команд не подходят.
4. Проверьте текущую папку командой `Get-Location`: путь должен оканчиваться на `vk_bot`. Командой `Get-ChildItem` посмотрите файлы: нужный `.py` и папка `.venv` должны быть здесь. Если папка другая, откройте правильную через File → Open Folder и создайте новый терминал. Если видите `>>>`, открыт интерактивный Python: введите `exit()` и Enter, чтобы вернуться к PowerShell.
5. После создания окружения запускайте нужный файл командой из блока ниже. Начальное `.\` означает «из текущей папки». Если PowerShell активировал среду автоматически, прямой путь всё равно подходит. Если `.venv` ещё нет, сначала выполните создание среды из занятия 2.

```powershell
.\.venv\Scripts\python.exe bot.py
```

6. Пока бот работает, приглашение `PS …>` не возвращается: терминал занят программой. Вопросы и команды боту отправляйте в **диалоге с сообществом VK**. Консольной программе ответ на `input` вводите в том же TERMINAL после её вопроса. Ключ вводится только после приглашения `Токен сообщества:`; символы `getpass` не отображаются.
7. Перед новой правкой щёлкните в TERMINAL и нажмите `Ctrl+C`, дождитесь приглашения PowerShell. Исправьте файл, сохраните `Ctrl+S`, снова выполните команду запуска. Работающая программа не подхватывает сохранённые изменения сама. Ошибки Python читаем в TERMINAL: последняя строка — тип и описание, выше — файл и номер строки. Кнопка Problems / Проблемы помогает найти синтаксические замечания, но не заменяет запуск.

### Шаг 1. Подключаем клавиатуру

**Где работаем:** VS Code → bot.py → группа импортов в начале.

**Действие:** Вверху bot.py после импортов Bots Long Poll добавьте импорт `VkKeyboard, VkKeyboardColor` из `vk_api.keyboard`. Слушатель событий не меняем.

**Порядок выполнения и ориентиры:** Добавьте одну строку from vk_api.keyboard import VkKeyboard, VkKeyboardColor рядом с импортом bot_longpoll. Сохраните и перезапустите, чтобы Python действительно проверил импорт.

**Что должно получиться:** После ввода ключа нет ImportError или ModuleNotFoundError. Если ошибка есть, проверьте написание и Python из .venv.

### Шаг 2. Создаём кнопки один раз

**Где работаем:** Редактор bot.py: после подготовки подключения, до for event.

**Действие:** Перед циклом событий создайте keyboard через `VkKeyboard(one_time=False)`. Добавьте кнопки «Начать» и «Помощь» вызовами `keyboard.add_button` с аргументом label. Для цвета используйте, например, `color=VkKeyboardColor.PRIMARY`. Затем вызовите `keyboard.add_line()` и добавьте «Покачай шар». Это обычные текстовые кнопки; callback-кнопки здесь не используем.

**Порядок выполнения и ориентиры:** Создайте keyboard без отступов, затем на том же уровне добавьте кнопки и новую строку. Не размещайте эти вызовы в цикле: иначе клавиатура будет создаваться для каждого события.

**Что должно получиться:** В файле один вызов VkKeyboard. Пока параметр отправки не добавлен, отсутствие кнопок в VK нормально.

**Проверка:** можете объяснить, какой текст отправит каждая кнопка.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Связываем нажатие и команду

**Где работаем:** Редактор bot.py: существующая цепочка if/elif перед else.

**Действие:** В цепочке if/elif перед else добавьте «покачай шар»: reply получает случайный элемент answers. Нажатие текстовой кнопки приходит тем же событием MESSAGE_NEW, что и набранный текст. Отдельный цикл не нужен.

**Порядок выполнения и ориентиры:** Добавьте проверку текста «покачай шар» в нижнем регистре. Внутри задайте reply через random.choice. Сохраните, перезапустите и наберите команду вручную в браузере.

**Что должно получиться:** Ручная команда выдаёт предсказание. Кнопка в следующем шаге отправит точно такой же текст.

**Проверка:** команда «Покачай шар», набранная вручную, работает.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Прикрепляем клавиатуру

**Где работаем:** Редактор bot.py: словарь единственного messages.send.

**Действие:** В единственный словарь параметров messages.send добавьте ключ `keyboard` со значением `keyboard.get_keyboard()`. Сохраните запятую между элементами словаря. Мы прикрепляем клавиатуру к каждому ответу, чтобы она не терялась.

**Порядок выполнения и ориентиры:** Найдите messages.send через Ctrl+F. Внутри его словаря, рядом с peer_id, message и random_id, добавьте элемент keyboard. После сохранения перезапустите бота и отправьте «Начать».

**Что должно получиться:** В диалоге появилась панель из заданных кнопок. При SyntaxError проверьте запятую после предыдущего элемента словаря.

**Проверка:** после «Начать» видны кнопки; каждая даёт один ответ.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Проверяем удобство

**Где работаем:** Браузер или приложение VK; открытый TERMINAL VS Code.

**Действие:** Нажмите все кнопки, затем отправьте обычный вопрос. Цвет — подсказка, а не поведение команды; вид оттенка зависит от клиента VK. Если кнопки скрыты, откройте панель клавиатуры в диалоге. Если нет совсем — проверьте возможности ботов, get_keyboard и параметры отправки.

**Порядок выполнения и ориентиры:** Нажмите «Начать», «Помощь» и «Покачай шар», затем введите вопрос с ?. Если клавиатура свёрнута, откройте её кнопкой панели ввода в клиенте VK.

**Что должно получиться:** После каждого действия приходит один подходящий ответ; терминал не показывает traceback.

**Проверка:** текст и кнопки используют одну логику.
