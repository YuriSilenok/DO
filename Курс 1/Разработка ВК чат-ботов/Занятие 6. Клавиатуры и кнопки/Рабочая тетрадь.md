# Часть 1. Классная работа

### Шаг 1. Импортируем классы для клавиатуры

**Что делаем.** В начало `bot.py`, сразу после `from vk_api.longpoll import ...`, добавляем строку импорта:

```python
from vk_api.keyboard import VkKeyboard, VkKeyboardColor
```

**Пояснение.** `VkKeyboard` — конструктор клавиатуры (создаёт «доску» с кнопками), а `VkKeyboardColor` — набор доступных цветов кнопок. Клавиатура — это панель с кнопками, которая появляется в приложении под полем ввода сообщения — как панель быстрого набора в телефоне. Сравните: команды можно печатать вручную (медленно, можно ошибиться), а кнопка запускает команду касанием (быстро и всегда правильно).

**Проверь себя.** Строка импорта добавлена, ошибок при запуске нет.

### Шаг 2. Создаём клавиатуру

**Что делаем.** Добавляем после подключения к сообществу код создания клавиатуры:

```python
keyboard = VkKeyboard(one_time=False)

keyboard.add_button("Начать", color=VkKeyboardColor.POSITIVE)
keyboard.add_line()
keyboard.add_button("Помощь", color=VkKeyboardColor.PRIMARY)
keyboard.add_line()
keyboard.add_button("Кто я", color=VkKeyboardColor.SECONDARY)
```

**Пояснение.** `one_time=False` означает, что клавиатура останется после нажатия (пользователь может жать кнопки сколько угодно). `add_button` добавляет кнопку на текущую строку, `add_line` — перенос на новую строку. Так мы получаем три строки по одной кнопке. `POSITIVE` — зелёный, `PRIMARY` — синий, `SECONDARY` — белый/серый. Цвет не влияет на логику, но помогает глазу: например, зелёный «Начать» выглядит как «главная» кнопка.

**Проверь себя.** В коде клавиатура создана один раз, до цикла.

### Шаг 3. Прикрепляем клавиатуру к сообщению

**Что делаем.** В ответе бота на команду «Начать» добавляем параметр `keyboard`:

```python
if user_text == "начать":
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": "Привет! Я магический шар. Задай вопрос или нажми кнопку!",
        "keyboard": keyboard.get_keyboard(),
        "random_id": 0
    })
```

**Пояснение.** `keyboard.get_keyboard()` превращает нашу клавиатуру в формат (JSON-строку), который понимает ВКонтакте. Без этого параметра клавиатура есть в коде, но не показывается пользователю — как свёрнутая панель, которую забыли развернуть. Теперь при команде «Начать» под полем ввода появятся наши три кнопки.

**Проверь себя.** После «Начать» под полем ввода видна панель с тремя кнопками.

### Шаг 4. Учим бота отвечать на кнопки

**Что делаем.** Добавляем команды для кнопок, которых пока нет в логике, — «Предскажи» и «Покачай шар»:

```python
elif user_text == "предскажи":
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": "Задай свой вопрос текстом — и я отвечу!",
        "random_id": 0
    })
elif user_text == "покачай шар":
    vk.method("messages.send", {
        "user_id": event.user_id,
        "message": random.choice(answers),
        "random_id": 0
    })
```

**Пояснение.** Кнопка `text` в клавиатуре ВКонтакте — это просто текст, который «нажимается» и отправляется как обычное сообщение. Поэтому для каждой кнопки нужна соответствующая команда `elif` — точно такая же, как для набранной с клавиатуры команды. Сравните: кнопка — это «горячая клавиша» для сообщения; чтобы она работала, само сообщение должно быть обработано ботом.

**Проверь себя.** Нажатия «Покачай шар» дают случайные предсказания, «Предскажи» — подсказку.

**Что делаем.** Проверяем «Оракула» целиком:
1) после «Начать» появляется клавиатура с кнопками;

4) цвета кнопок совпадают с выбранными в коде.

**Как проверить правильность выполнения домашней работы**

Проверьте себя по чек-листу — работа выполнена верно, если выполняется **всё** из списка:

1. **Клавиатура есть.** После «Начать» появляется панель кнопок.
2. **Все кнопки работают.** «Помощь», «Кто я» и ваша кнопка дают правильные ответы.
3. **Кнопка — ваша.** На клавиатуре есть придуманная вами кнопка, а в коде — команда `elif` под её текст.
4. **Цвета выбраны.** Кнопки выглядят так, как задано в коде (задание 4).
5. **Ответы верные.** Клавиатура делает команды заметными и удобными (не надо печатать); без `get_keyboard()` клавиатура не отправится в чат; кнопка `text` просто отправляет текст, поэтому работает в уже готовой логике команд.
6. **Безопасность.** Токен «Оракула» нигде не показан.

**Если какой-то пункт не выполняется** — проверьте, что `keyboard` прикреплён именно в сообщении «Начать», и что текст кнопки точно совпадает с проверяемой командой.
