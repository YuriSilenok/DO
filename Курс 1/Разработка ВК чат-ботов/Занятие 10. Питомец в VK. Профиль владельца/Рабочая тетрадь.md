## Классная работа

### Шаг 1. Заменяем назначение бота

В pet_bot.py измените приветствие и помощь: это виртуальный питомец. Удалите ветки предсказаний и кнопки шара, добавьте кнопки «Питомец» и «Приютить». Уберите неиспользуемые answers и random. Сохраните получение событий, фильтр личного диалога, getpass и единую отправку ответа.

**Проверка:** сообщения VK доходят; прежние команды шара не выдают случайных предсказаний.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Открываем БД один раз

Подключите sqlite3 и Path, перенесите путь pets.db рядом с pet_bot.py. Перед циклом подключите conn, создайте таблицу pets с теми же пятью полями, что на занятии 9, и сохраните создание через commit. Не открывайте соединение для каждого сообщения. Сам цикл поместите в try, а conn.close() — в finally после цикла. Если использовали консольную БД с учебными ID, это не реальные профили VK; не выводите их другим пользователям.

**Проверка:** соединение создаётся до listen и закрывается при Ctrl+C.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Выносим чтение в функцию

Между импортами и кодом подключения определите `def get_pet(conn, owner_id):`. В теле создайте локальный курсор, выполните SELECT owner_id, name, satiety, mood, xp FROM pets WHERE owner_id = ? с кортежем параметра и верните fetchone через return. Функция принимает соединение и ID, ничего не печатает и не отправляет в VK. def только описывает действие, вызов выполняет его.

**Проверка:** get_pet(conn, отсутствующий_ID) возвращает None; порядок полей всегда одинаков.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Приютили один раз

В ветке «приютить» выполните INSERT OR IGNORE только с owner_id и name: ID берите из user_id входящего события, имя пока «Искра». Затем commit. По cur.rowcount различите новую строку (1) и уже существующую (0). Существующего питомца не заменяйте. reply сообщает результат.

**Проверка:** повторная команда не сбрасывает питомца.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Показываем карточку

В ветке «питомец» вызовите get_pet(conn, user_id). Если None — предложите «Приютить». Иначе соберите reply из name, satiety, mood и xp с помощью f-строки. Индексы кортежа: 0 — owner_id, 1 — name, 2 — satiety, 3 — mood, 4 — xp. Остальные неизвестные сообщения направляйте в помощь.

**Проверка:** у нового пользователя есть понятная подсказка; у владельца — карточка.

- [ ] Получилось; могу объяснить изменение.

### Шаг 6. Проверяем изоляцию

С двумя участниками группы проверьте два разных user_id: один приютил питомца, второй сначала видит предложение приютить своего. Не добавляйте команду просмотра чужого ID. Остановите и запустите процесс; профиль должен сохраниться.

**Проверка:** один владелец не видит карточку другого.

- [ ] Получилось; могу объяснить изменение.
