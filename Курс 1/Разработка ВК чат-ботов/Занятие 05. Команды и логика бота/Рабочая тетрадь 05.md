## Как выполнять действия в VS Code

1. Откройте **File → Open Folder / Файл → Открыть папку** и выберите свою папку `vk_bot`. Слева в **Explorer / Проводник** (`Ctrl+Shift+E`) находятся файлы, в центре — редактор выбранного файла. Файлы `.py` создавайте в корне `vk_bot`, не внутри `.venv`.
2. Код Python вводите в центральный редактор файла `.py`, затем нажимайте `Ctrl+S`. Точка на вкладке означает несохранённые изменения. Фрагменты SQL помещайте в кавычках в аргументы `execute` в Python-файле; их не вводят как команды PowerShell.
3. Команды установки и запуска вводите внизу: **Terminal → New Terminal / Терминал → Создать терминал**. В этой тетради для Windows используется **PowerShell**. Щёлкните после приглашения `PS …>`, наберите команду без самого приглашения и нажмите `Enter`. Панели **Output / Вывод** и **Debug Console / Консоль отладки** для этих команд не подходят.
4. Проверьте текущую папку командой `Get-Location`: путь должен оканчиваться на `vk_bot`. Командой `Get-ChildItem` посмотрите файлы: нужный `.py` и папка `.venv` должны быть здесь. Если папка другая, откройте правильную через File → Open Folder и создайте новый терминал. Если видите `>>>`, открыт интерактивный Python: введите `exit()` и Enter, чтобы вернуться к PowerShell.
5. После создания окружения запускайте нужный файл командой из блока ниже. Начальное `.\` означает «из текущей папки». Если PowerShell активировал среду автоматически, прямой путь всё равно подходит. Если `.venv` ещё нет, сначала выполните создание среды из занятия 2.

```powershell
.\.venv\Scripts\python.exe bot.py
```

6. Пока бот работает, приглашение `PS …>` не возвращается: терминал занят программой. Вопросы и команды боту отправляйте в **диалоге с сообществом VK**. Консольной программе ответ на `input` вводите в том же TERMINAL после её вопроса. Ключ вводится только после приглашения `Токен сообщества:`; символы `getpass` не отображаются.
7. Перед новой правкой щёлкните в TERMINAL и нажмите `Ctrl+C`, дождитесь приглашения PowerShell. Исправьте файл, сохраните `Ctrl+S`, снова выполните команду запуска. Работающая программа не подхватывает сохранённые изменения сама. Ошибки Python читаем в TERMINAL: последняя строка — тип и описание, выше — файл и номер строки. Кнопка Problems / Проблемы помогает найти синтаксические замечания, но не заменяет запуск.

## Как копировать учебные блоки

Копируйте **по одному блоку до 10 строк**, а не весь материал занятия. Перед каждым блоком указаны файл, место вставки или замены и причина такого расположения. Несколько блоков одного шага выполняйте по порядку. Если код уже набран по описанию, второй раз его не добавляйте — сравните с образцом.

Сохраняйте начальные пробелы: они показывают вложенность Python. После вставки проверьте выравнивание с названными соседними строками; VS Code может автоматически добавить лишний отступ. Код с меткой `python` идёт в редактор `.py`, `powershell` — в TERMINAL Windows, `bash` — в Termux. Номер шага, пояснение и ограждения из трёх обратных кавычек в файл не переносятся. В блоках нет скрытого продолжения в виде троеточия: если блок открывает try или функцию, явно указано, каким следующим блоком завершить сборку до запуска.

### Шаг 3. Добавляем помощь и представление

**Где работаем:** Редактор bot.py: между первым if и последним else.

**Действие:** Между первым if и последним else добавьте две ветки elif: для «помощь» с описанием команд и для «кто ты» с представлением шара. Каждая ветка только задаёт reply. Новые условия нельзя дописывать после else.

**Порядок выполнения и ориентиры:** Вставьте две ветки elif на том же уровне отступа, что if; их reply — на один отступ глубже. В каждую ветку впишите свой текст. Сохраните и перезапустите бота.

**Блок 3.1 · куда вставить:** Между веткой «начать» и последним else. Отступ elif совпадает с первым if: 8 пробелов.

**Зачем и почему здесь:** Elif проверяется только если предыдущая команда не подошла; поэтому нет нескольких ответов на одно сообщение.

```python
        elif user_text == "помощь":
            reply = "Команды: Начать, Помощь, Кто ты. Задай вопрос с ?."
        elif user_text == "кто ты":
            reply = "Я Магический шар — игра со случайными ответами."
```

**Что должно получиться:** В браузере по очереди отправьте «Помощь» и «Кто ты»: увидите два разных ответа без лишнего предсказания.

**Проверка:** все три команды возвращают разные осмысленные ответы.

### Шаг 4. Распознаём вопрос

**Где работаем:** Редактор bot.py: конец цепочки условий до отправки.

**Действие:** Перед финальным else добавьте ветку для пустого user_text с просьбой прислать текст. Затем ветку с `user_text.endswith("?")` и случайным ответом. Последний else теперь предлагает написать вопрос со знаком вопроса. Удалите прежний случайный ответ из else. Это правило нашего интерфейса, а не понимание смысла текста.

**Порядок выполнения и ориентиры:** Пустой текст проверяйте перед вопросом, вопрос со знаком ? — перед последним else. Замените содержимое прежнего else подсказкой. После сохранения и перезапуска проверяйте текст в VK, не в терминале с токеном.

**Блок 4.1 · куда вставить:** Замените последний else вместе с его присваиванием reply. Остальные if/elif выше и отправка ниже остаются.

**Зачем и почему здесь:** Пустой текст и вопрос распознаются перед запасной подсказкой. Else завершает всю цепочку.

```python
        elif not user_text:
            reply = "Напиши вопрос текстом."
        elif user_text.endswith("?"):
            reply = random.choice(answers)
        else:
            reply = "Задай вопрос со знаком ? или напиши Помощь."
```

**Что должно получиться:** «Да?» даёт предсказание, «Да» — подсказку, стикер без текста — просьбу написать текст. Ответ в каждом случае один.

**Проверка:** текст без ? даёт подсказку, вопрос с ? — предсказание; стикер без текста не ломает бота.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Используем f-строку

**Действие:** Добавьте до else команду «мой номер». Для неё сформируйте reply как f-строку с user_id в фигурных скобках. Это числовой ID, а не имя человека. Дополнительный вызов users.get для этого не нужен.

**Порядок выполнения и ориентиры:** Добавьте elif для «мой номер», присваивание reply начните с f перед кавычкой; user_id укажите в фигурных скобках внутри строки. Не заключайте само имя переменной в дополнительные кавычки.

**Блок 5.1 · куда вставить:** Перед последним else, после остальных elif. Не вставляйте между else и его телом.

**Зачем и почему здесь:** Команда должна быть проверена до общего ответа; user_id уже получен из события выше.

```python
        elif user_text == "мой номер":

```

**Что должно получиться:** После перезапуска команда «Мой номер» в VK возвращает цифры, а не буквальный текст {user_id}.

**Проверка:** команда выводит ID отправителя.
