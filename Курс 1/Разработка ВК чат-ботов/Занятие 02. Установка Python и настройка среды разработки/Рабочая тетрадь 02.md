## Что куда вводить

Пока VS Code не установлен, команду проверки Python вводим в Windows PowerShell из меню «Пуск». После установки редактора используем встроенный TERMINAL VS Code. Код print вводим в центральную вкладку first.py; команды py, pip и запуск файла — в TERMINAL. После каждой команды нажимаем Enter, после правки файла — Ctrl+S. Ниже каждый шаг указывает нужное окно.

## Как копировать учебные блоки

Копируйте **по одному блоку до 10 строк**, а не весь материал занятия. Перед каждым блоком указаны файл, место вставки или замены и причина такого расположения. Несколько блоков одного шага выполняйте по порядку. Если код уже набран по описанию, второй раз его не добавляйте — сравните с образцом.

Сохраняйте начальные пробелы: они показывают вложенность Python. После вставки проверьте выравнивание с названными соседними строками; VS Code может автоматически добавить лишний отступ. Код с меткой `python` идёт в редактор `.py`, `powershell` — в TERMINAL Windows, `bash` — в Termux. Номер шага, пояснение и ограждения из трёх обратных кавычек в файл не переносятся. В блоках нет скрытого продолжения в виде троеточия: если блок открывает try или функцию, явно указано, каким следующим блоком завершить сборку до запуска.

## Классная работа

### Шаг 1. Устанавливаем Python

**Где работаем:** Браузер, установщик Python, затем Windows PowerShell.

**Действие:** Скачайте Python Install Manager с [python.org](https://www.python.org/downloads/). Установите стабильную версию Python по подсказкам менеджера. Откройте новый терминал и выполните `py --version`. Если Python уже установлен и команда показывает Python 3, повторная установка не нужна.

**Порядок выполнения и ориентиры:** До установки VS Code откройте PowerShell через меню «Пуск»: в поиске наберите PowerShell и запустите приложение. После установки Python откройте новое окно, щёлкните после приглашения PS, введите py --version и нажмите Enter.

**Что должно получиться:** Под командой появилась строка Python 3.x.x. Если команда не найдена, закройте PowerShell и откройте снова; не вводите команду в адресную строку браузера.

### Шаг 2. Устанавливаем редактор

**Где работаем:** VS Code: боковая панель расширений и меню File / Файл.

**Действие:** Установите [VS Code](https://code.visualstudio.com/) и расширение Python от Microsoft. Создайте папку `vk_bot` и откройте её через File → Open Folder.

**Порядок выполнения и ориентиры:** Откройте Extensions сочетанием Ctrl+Shift+X, найдите Python от Microsoft и нажмите Install. Через File → Open Folder выберите заранее созданную папку vk_bot. Откройте Explorer сочетанием Ctrl+Shift+E.

**Как создать папку:** откройте Проводник Windows сочетанием `Win+E`, перейдите в «Документы», нажмите `Ctrl+Shift+N`, введите `vk_bot` и нажмите `Enter`. Вернитесь в VS Code, выберите File → Open Folder, найдите эту папку и нажмите «Выбор папки». В дальнейшем открывайте её же, чтобы не создавать несколько разных проектов.

**Что должно получиться:** Слева виден заголовок VK_BOT, у расширения нет кнопки Install. Работать нужно с папкой проекта, а не только с отдельно открытым файлом.

**Проверка:** видите папку проекта в проводнике VS Code.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Отделяем зависимости

**Где работаем:** VS Code → Terminal → New Terminal; затем палитра команд.

**Действие:** В терминале VS Code из папки проекта выполните `py -m venv .venv`. В палитре команд выберите Python: Select Interpreter и интерпретатор `.venv`. Окружение — отдельный набор библиотек для проекта. В следующих командах Windows используем прямой путь к нему: активация PowerShell не требуется.

**Порядок выполнения и ориентиры:** Внизу откроется TERMINAL. В выпадающем списке профилей выберите PowerShell, если открыт другой терминал. Введите Get-Location и Enter: путь должен вести в vk_bot. Только затем выполните py -m venv .venv. Нажмите Ctrl+Shift+P, наберите Python: Select Interpreter, выберите путь .venv/Scripts/python.exe. Если его нет, укажите через Enter interpreter path.

**Блок 3.1 · куда вставить:** В нижний TERMINAL VS Code с профилем PowerShell, после проверки папки vk_bot. Это команда, не содержимое Python-файла.

**Зачем и почему здесь:** Создаём окружение именно внутри проекта: последующие установки будут относиться к нему.

```powershell
py -m venv .venv
```

**Что должно получиться:** Слева появилась папка .venv. В терминале выполните `.\.venv\Scripts\python.exe --version`: увидите Python 3.x.x. Не выбирайте для проекта глобальный Python, если уже создана .venv.

**Проверка:** команда `.venv\Scripts\python.exe --version` выводит версию.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Пишем первую строку

**Где работаем:** VS Code → Explorer → новый файл first.py; запуск в нижнем TERMINAL.

**Действие:** Создайте `first.py`. Вызовите `print` с собственной фразой приветствия «Магического шара»: текст поместите в кавычки внутри круглых скобок. Сохраните файл. Запустите `.venv\Scripts\python.exe first.py`.

**Порядок выполнения и ориентиры:** Наведите курсор на папку VK_BOT, нажмите значок New File, введите first.py и Enter. Щёлкните в центральном редакторе, наберите вызов print, нажмите Ctrl+S. Внизу в PowerShell выполните `.\.venv\Scripts\python.exe first.py`.

**Блок 4.1 · куда вставить:** В пустой first.py, в центральном редакторе. Измените текст внутри кавычек на свой.

**Зачем и почему здесь:** print выводит приветствие; на этом шаге проверяем запуск самого простого файла.

```python
print("Привет! Я Магический шар.")
```

**Блок 4.2 · куда вставить:** В TERMINAL, после Ctrl+S в first.py.

**Зачем и почему здесь:** Вызываем Python созданного окружения и передаём ему файл проекта.

```powershell
.\.venv\Scripts\python.exe first.py
```

**Что должно получиться:** В TERMINAL видна ваша фраза, после неё снова приглашение PS. Если открылся first.py.txt, переименуйте файл в Explorer: расширение должно быть .py.

**Проверка:** терминал вывел вашу фразу один раз.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Находим ошибку

**Где работаем:** Редактор first.py и TERMINAL VS Code.

**Действие:** Временно уберите закрывающую кавычку, сохраните и запустите файл. Найдите имя файла, строку и описание SyntaxError. Верните кавычку и повторите запуск. Если команда открывает магазин или не найдена, проверьте установку Python и путь к окружению.

**Порядок выполнения и ориентиры:** Измените кавычку именно в центральной вкладке first.py, сохраните Ctrl+S и повторите команду запуска в терминале стрелкой вверх и Enter. После чтения ошибки верните кавычку, сохраните и повторите запуск.

**Что должно получиться:** Первый запуск показывает SyntaxError и номер строки, второй — вашу фразу без этой ошибки. Нажатие Ctrl+S само программу не запускает.

**Проверка:** можете показать, где читать сообщение об ошибке.
