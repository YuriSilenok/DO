## Классная работа

### Шаг 1. Создаём учебное сообщество

Откройте VK → «Сообщества» → создание сообщества. Назовите его «Магический шар». Выбирайте доступный формат сообщества для проекта. Откройте его настройки управления. Названия и расположение пунктов могут отличаться: ищите раздел по назначению, а не по месту старой кнопки.

**Проверка:** вы можете открыть управление своим сообществом.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Включаем сообщения

В управлении найдите «Сообщения», включите сообщения сообщества и сохраните настройку. Если есть раздел «Настройки для бота», включите возможности ботов. На этом этапе автоответа ещё нет.

**Проверка:** с личного аккаунта можно отправить сообществу сообщение.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Создаём ключ

Найдите «Работа с API» → «Ключи доступа» (раздел может находиться в «Дополнительно»). Создайте ключ сообщества. Нужны сообщения (`messages`), а для получения настроек Long Poll через используемую библиотеку — управление (`manage`). Если VK требует подтверждения, выполните его в официальном интерфейсе. Сохраните ключ локально, не в общей тетради.

**Проверка:** ключ создан; в тетради записано только «сохранён», без значения ключа.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Настраиваем события

В «Работа с API» найдите Long Poll API, включите его и сохраните. В типах событий включите «Входящее сообщение» (`message_new`). Это Bots Long Poll для сообщества. Не настраивайте Callback-сервер: в этом курсе он не нужен. Если интерфейс предлагает версию API, запишите выбранную и согласуйте её с преподавателем перед занятием 4.

**Проверка:** Long Poll включён, message_new отмечен, изменения сохранены.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Записываем ID

Узнайте числовой ID сообщества в его настройках или адресе вида `club123456789` / `public123456789`. Короткое имя сообщества не является числовым ID. Запишите только положительное число и ссылку на сообщество.

**Проверка:** есть ID, ссылка и тестовое входящее сообщение; отсутствие ответа пока нормально.

- [ ] Получилось; могу объяснить изменение.

### Шаг 6. Разбираемся с секретом

Токен позволяет действовать от имени сообщества. Не отправляйте его даже вместе с кодом преподавателю: для проверки достаточно кода без секрета. Если ключ попал в общий чат или репозиторий, отзовите его в VK и создайте новый.

**Проверка:** можете объяснить разницу между публичным ID и секретным токеном.

- [ ] Получилось; могу объяснить изменение.
