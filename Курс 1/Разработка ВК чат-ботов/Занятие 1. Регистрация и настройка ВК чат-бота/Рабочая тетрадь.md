## Классная работа

### Шаг 1. Создаём учебное сообщество

**Где работаем:** Браузер, сайт VK; VS Code сегодня не требуется.

**Действие:** Откройте VK → «Сообщества» → создание сообщества. Назовите его «Магический шар». Выбирайте доступный формат сообщества для проекта. Откройте его настройки управления. Названия и расположение пунктов могут отличаться: ищите раздел по назначению, а не по месту старой кнопки.

**Порядок выполнения и ориентиры:** В адресную строку браузера введите vk.com/groups. Войдите в аккаунт. Нажмите создание сообщества, заполните название и завершите создание. После открытия страницы найдите управление сообществом.

**Что должно получиться:** Обновите страницу: название осталось, а управление доступно. Если управления нет, проверьте, что вошли как владелец или администратор.

**Проверка:** вы можете открыть управление своим сообществом.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Включаем сообщения

**Где работаем:** Браузер → управление учебным сообществом → сообщения.

**Действие:** В управлении найдите «Сообщения», включите сообщения сообщества и сохраните настройку. Если есть раздел «Настройки для бота», включите возможности ботов. На этом этапе автоответа ещё нет.

**Порядок выполнения и ориентиры:** Откройте настройки сообщений, включите приём и нажмите сохранение, если оно предусмотрено. Затем вернитесь на страницу сообщества и откройте личный диалог с ним.

**Что должно получиться:** Отправьте «Проверка». Сообщение появилось в диалоге без ошибки отправки. Ответа бота пока не ожидаем.

**Проверка:** с личного аккаунта можно отправить сообществу сообщение.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Создаём ключ

**Где работаем:** Браузер → настройки сообщества → работа с API → ключи доступа.

**Действие:** Найдите «Работа с API» → «Ключи доступа» (раздел может находиться в «Дополнительно»). Создайте ключ сообщества. Нужны сообщения (`messages`), а для получения настроек Long Poll через используемую библиотеку — управление (`manage`). Если VK требует подтверждения, выполните его в официальном интерфейсе. Сохраните ключ локально, не в общей тетради.

**Порядок выполнения и ориентиры:** В окне создания ключа отметьте нужные права и подтвердите действие. Сохраните ключ в личном защищённом месте; в рабочей тетради поставьте только отметку о сохранении.

**Что должно получиться:** Снова откройте список ключей: ключ присутствует. Его значение не должно быть видно на экране, который вы показываете группе.

**Проверка:** ключ создан; в тетради записано только «сохранён», без значения ключа.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Настраиваем события

**Где работаем:** Браузер → работа с API → Long Poll API.

**Действие:** В «Работа с API» найдите Long Poll API, включите его и сохраните. В типах событий включите «Входящее сообщение» (`message_new`). Это Bots Long Poll для сообщества. Не настраивайте Callback-сервер: в этом курсе он не нужен. Если интерфейс предлагает версию API, запишите выбранную и согласуйте её с преподавателем перед занятием 4.

**Порядок выполнения и ориентиры:** Сначала включите Long Poll и сохраните. Затем откройте типы событий, отметьте входящее сообщение и снова сохраните. Вернитесь на эту вкладку после обновления страницы.

**Что должно получиться:** Включённое состояние и галочка message_new сохранились. Если сбросились, повторите сохранение и проверьте права аккаунта.

**Проверка:** Long Poll включён, message_new отмечен, изменения сохранены.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Записываем ID

**Где работаем:** Браузер и поля для записей в тетради.

**Действие:** Узнайте числовой ID сообщества в его настройках или адресе вида `club123456789` / `public123456789`. Короткое имя сообщества не является числовым ID. Запишите только положительное число и ссылку на сообщество.

**Порядок выполнения и ориентиры:** Откройте сведения о сообществе или его числовой адрес. Перепишите число без club/public и без знака минус. Если виден только короткий адрес, найдите числовой ID в настройках вместе с преподавателем.

**Что должно получиться:** Записаны ссылка и число, состоящее только из цифр. Не записывайте вместо ID название сообщества.

**Проверка:** есть ID, ссылка и тестовое входящее сообщение; отсутствие ответа пока нормально.

- [ ] Получилось; могу объяснить изменение.

### Шаг 6. Разбираемся с секретом

**Где работаем:** Личная запись с ключом и настройки ключей в браузере.

**Действие:** Токен позволяет действовать от имени сообщества. Не отправляйте его даже вместе с кодом преподавателю: для проверки достаточно кода без секрета. Если ключ попал в общий чат или репозиторий, отзовите его в VK и создайте новый.

**Порядок выполнения и ориентиры:** Проверьте, что ключ не скопирован в описание сообщества, общую тетрадь или переписку группы. Устно объясните, где его вводить при будущем запуске.

**Что должно получиться:** Преподавателю показываете отметку о сохранении и публичный ID, а не сам ключ.

**Проверка:** можете объяснить разницу между публичным ID и секретным токеном.

- [ ] Получилось; могу объяснить изменение.
