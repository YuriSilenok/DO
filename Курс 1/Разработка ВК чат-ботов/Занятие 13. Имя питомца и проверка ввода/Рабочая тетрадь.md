## Классная работа

### Шаг 1. Сохраняем исходный текст

Там, где читается событие, сохраните `raw_text = message.text.strip()`. Из него получите user_text через lower для команд. Имя извлекайте из raw_text, иначе «Луна» превратится в «луна». Прежнюю строку нормализации замените, не оставляйте две независимые версии.

**Проверка:** команды по-прежнему нечувствительны к регистру.

- [ ] Получилось; могу объяснить изменение.

### Шаг 2. Распознаём команду с аргументом

Перед else добавьте условие: user_text равен «имя» либо начинается с «имя » через startswith. Разбейте raw_text методом split(maxsplit=1). Если получился один элемент — покажите пример «Имя Луна». Если два — второй элемент является новым именем; примените strip.

**Проверка:** «Имя» даёт подсказку, «ИМЯ Луна» сохраняет регистр имени; «имярек» не считается командой.

- [ ] Получилось; могу объяснить изменение.

### Шаг 3. Проверяем значение

До SQL проверьте длину нового имени: от 2 до 20 символов через len. Слишком короткое или длинное значение не сохраняйте. Пробелы внутри имени разрешены. Кавычки тоже: их корректно обрабатывают SQL-параметры. Для отсутствующего питомца сначала предложите приютить.

**Проверка:** ошибочный ввод не меняет прежнее имя.

- [ ] Получилось; могу объяснить изменение.

### Шаг 4. Меняем только имя

Добавьте rename_pet(conn, owner_id, new_name). Внутри выполните UPDATE pets SET name = ? WHERE owner_id = ? с параметрами (new_name, owner_id), затем commit. Не используйте INSERT OR REPLACE: он может заменить строку и сбросить показатели. Верните rowcount и сообщите результат в ветке команды.

**Проверка:** после переименования опыт, сытость и настроение прежние.

- [ ] Получилось; могу объяснить изменение.

### Шаг 5. Собираем набор проверок

Проверьте имя из двух слов, апостроф, длину 1, 2, 20, 21, команду без аргумента и перезапуск. Обновите помощь: «Имя <новое имя>». Скобки в описании обозначают место ввода, а не обязательные символы.

**Проверка:** допустимые имена сохраняются; ошибка не ломает цикл.

- [ ] Получилось; могу объяснить изменение.
