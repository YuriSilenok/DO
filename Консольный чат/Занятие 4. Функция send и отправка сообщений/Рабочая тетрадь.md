### Шаг 2. Функция send: данные, запрос, ответ

**Что делаем.** Пишем функцию `send` целиком.

**Как это работает.** Функция получает имя автора и текст, кладёт их в `data` и отправляет через `post("send", data=data)`. По ответу понимаем, доставлено ли сообщение.

**Пишем.** После `join` набираем:

```python
def send(username, text):
    data = {"username": username, "text": text}
    response = post("send", data=data)
    if not response or not response.get("ok"):
        print("Не удалось отправить сообщение")
        return False
    print("Отправлено:", text)
    return True
```

**Как это работает.**

1. `data = {"username": username, "text": text}` — собираем сообщение.
2. `post("send", data=data)` — функция `post` сама добавит `action: "send"` (вспомните занятие 2: `data["action"] = path`).
3. Показываем результат: успех или понятное сообщение об ошибке.
4. Возвращаем `True`/`False`, чтобы внешний код знал, попала ли строка в чат.

### Шаг 3. Когда сервер отвечает ошибкой

**Что делаем.** Учимся читать ответы сервера и не пугаться `ok: false`.

**Как это работает.** Есть типичные случаи, когда отправка «не проходит»:

- автор не входил в чат (`username` неизвестен);
- текст пустой или слишком длинный;
- сообщение пришло в неверном формате (`json.loads` не смог разобрать).

Во всех этих случаях в ответе будет либо `None` (мы не смогли достучаться), либо словарь с `ok: false` и текстом ошибки. Наша функция печатает «Не удалось отправить сообщение» и возвращает `False`.

