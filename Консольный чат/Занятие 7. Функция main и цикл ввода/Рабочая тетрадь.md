# Часть 1. Классная работа

### Шаг 1. Начало main: вход в чат

**Что делаем.** Пишем первую часть `main` — вход в чат и чтение имени.

**Как это работает.** Всё начинается с `join()`, которая возвращает имя и номер последнего сообщения. Если войти не удалось (вернулось `None, None`) — дальше работать нечего, и функция заканчивается.

**Пишем.** После `message_str` набираем:

```python
def main():
    username, last = join()
    if username is None:
        return
    ...
```

**Как это работает.**

1. `username, last = join()` — распаковываем два значения, которые мы вернули ещё на занятии 3.
2. `if username is None: return` — если войти не получилось, прекращаем работу с понятным сообщением от `join`.
3. Дальше (на следующих шагах) появятся цикл ввода и вывод сообщений.

### Шаг 2. Цикл ввода: похоже на калькулятор

**Что делаем.** Пишем главный цикл `while`, который работает, пока пользователь не выйдет.

**Как это работает.** Мы уже видели такой цикл в программе-калькуляторе: пока истина — спрашиваем строку, обрабатываем её, снова спрашиваем. В чате правило простое:

```
пока работает:
    у новых сообщений узнать всё новое и напечатать
    спросить у пользователя строку
    если пустая — ничего не делать
    если равна "exit" — выйти
    иначе — отправить как сообщение
```

**Пишем.** Продолжаем функцию `main`:

```python
def main():
    username, last = join()
    if username is None:
        return
    while True:
        messages = poll(last)
        for message in messages:
            print(message_str(message))
            last = message.get("id", last)
        text = input("> ")
        if not text:
            continue
        if text == "exit":
            break
        send(username, text)
```

**Как это работает.**

1. `messages = poll(last)` — спросили сервер, что нового после `last`.
2. `for message in messages` — прошлись по новым сообщениям и напечатали их.
3. `last = message.get("id", last)` — **обновили точку отсчёта**, чтобы не получать те же сообщения повторно. Вот для чего нужен `id`!
4. `text = input("> ")` — спросили строку у пользователя.
5. `if not text: continue` — пустая строка (просто Enter) — пропускаем ход.
6. `if text == "exit": break` — по команде выходим из цикла.
7. `send(username, text)` — всё остальное отправляем как сообщение в чат.

Цикл бесконечный, но выход из него даёт команда `exit`.

**Проверь себя.** Запустите `python chat.py` (если в конце файла уже есть вызов `main()`). При входе должно появиться приветствие, курсор `>`, и на `exit` программа завершится.

### Шаг 3. Почему сообщения «приходят» только когда мы печатаем

**Что делаем.** Разбираемся в ограничении простого цикла ввода.

**Как это работает.** В нашем цикле мы проверяем новые сообщения **только в начале каждой итерации** — то есть прямо перед тем, как спросить у пользователя очередную строку. Пока мы думаем над ответом, программа стоит на `input("> ")` и ничего не делает. Чужие сообщения появятся на экране только после того, как мы нажмём Enter.

Это нормально для первого рабочего варианта. На занятии 8 мы запустим проверку сообщений **в фоновой нити**, и тогда сообщения будут появляться, даже когда курсор ждёт ввода.
