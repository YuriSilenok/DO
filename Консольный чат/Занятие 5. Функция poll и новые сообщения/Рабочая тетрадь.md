### Шаг 2. Функция poll: спрашиваем «что нового?»

**Что делаем.** Пишем функцию `poll` — она принимает `last` и возвращает список новых сообщений.

**Как это работает.** Функция отправляет `post("poll", params)` с номером последнего просмотренного сообщения. Сервер присылает словарь, а в ключе `messages` лежит список сообщений, которые появились **после** этого номера.

**Пишем.** После `send` набираем:

```python
def poll(last):
    response = post("poll", params={"last": last})
    if not response or not response.get("ok"):
        return []
    return response.get("messages", [])
```

**Как это работает.**

1. `params={"last": last}` — номер сообщения, после которого мы хотим всё узнать. Спойлер: `post` склеит его с `action: "poll"`.
2. `if not response or not response.get("ok")` — не достучались или сервер отказал: возвращаем пустой список.
3. `response.get("messages", [])` — вытаскиваем список сообщений; если ключа нет — пустой список.

Почему возвращать список, а не словарь? Потому что «новых сообщений» может быть ноль, одно или много — удобно, когда функция всегда отдаёт список: вызывающий код может просто перебрать его циклом `for`.

### Шаг 3. Список сообщений и следующий last

**Что делаем.** Разбираемся, как двигаться по сообщениям и не получать их повторно.

**Как это работает.** Каждое сообщение — это словарь с ключами `id`, `text`, `username`. Если в чате пусто, сервер вернёт пустой список. Если сообщения есть — в списке будет их порядок, а `last` для следующего запроса надо взять как **номер последней записи**. Так мы никогда не пропустим сообщение и не получим одно и то же дважды. (Как именно это свяжется с циклом ввода — увидим на занятии 7.)
