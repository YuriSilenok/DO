### Шаг 2. Почему файл называется chat.py и зачем нужны импорты

**Что делаем.** Разбираемся, как устроен `chat.py`, и пишем первую часть — строку-кодировку, docstring и импорты.

**Как это работает.**

- Имя `chat.py` — это программа-клиент для чата. Python не требует особых имён: главное, чтобы имя было понятным и заканчивалось на `.py`.
- Строка `# -*- coding: utf-8 -*-` подсказывает Python, что файл написан в кодировке UTF-8 — иначе русские буквы могут превратиться в «кракозябры».
- Текст в тройных кавычках — это **docstring** (описание модуля). Python его игнорирует, а люди читают, чтобы понять, что делает программа.
- **Импорты** подключают готовые модули из стандартной библиотеки Python — ничего дополнительно устанавливать не нужно:

| Модуль | Что даёт |
|---|---|
| `json` | превращает данные в JSON-строку и обратно |
| `os` | читает переменные окружения |
| `threading` | запускает фоновые нити (понадобится на занятии 8) |
| `time` | делает паузы |
| `urllib.error` | понимает ошибки HTTP |
| `urllib.request` | отправляет запросы на сервер |

**Пишем.** Набираем в начале файла `chat.py` (в папке `Мой чат`):

```python
# -*- coding: utf-8 -*-
"""Консольный текстовый чат-клиент для chat_api.

Только текст: без картинок и файлов. Хост и порт можно поменять
переменными окружения CHAT_HOST / CHAT_PORT (по умолчанию силенок.рф:8000).

Запуск:  python chat.py
"""

import json
import os
import threading
import time
import urllib.error
import urllib.request
```

### Шаг 3. Функция base_url: откуда взять адрес сервера

**Что делаем.** Пишем функцию, которая собирает адрес сервера: хост и порт.

**Как это работает.** Перед тем как отправлять запросы, надо понять, **куда** их отправлять. Адрес сервера состоит из двух частей:

- **хост** — имя компьютера или сайта, где живёт сервер (у нас `силенок.рф`);
- **порт** — «дверь», через которую стучится клиент (у нас `8000`).

Жёстко вписывать адрес в код — плохая идея: пришлось бы менять программу ради одной строчки. Python умеет читать **переменные окружения** — настройки операционной системы. Будем брать хост из `CHAT_HOST`, порт из `CHAT_PORT`, а если они не заданы — подставлять значения по умолчанию.

Отдельная **функция** `base_url()` нужна потому, что адрес используется в нескольких местах программы. Напишем его вычисление один раз, а дальше будем просто вызывать функцию.

**Пишем.** После импортов набираем:

```python
def base_url():
    host = os.getenv("CHAT_HOST", "силенок.рф")
    try:
        host = host.encode("idna").decode("ascii")  # кириллический домен -> punycode
    except UnicodeError:
        pass
    port = os.getenv("CHAT_PORT", "8000")
    return "http://{}:{}".format(host, port)
```

**Как это работает.**

1. `os.getenv("CHAT_HOST", "силенок.рф")` — берём хост из переменной окружения, а если её нет — используем `силенок.рф`.
2. `host.encode("idna").decode("ascii")` — переводим кириллический домен в «компьютерный» вид (punycode): обычные программы не понимают русские буквы в адресе. Если домен уже английский — ничего не меняется.
3. `except UnicodeError` — если домен вдруг окажется не строкой, программа не упадёт, а пойдёт дальше.
4. Порт берём так же: из `CHAT_PORT` или `8000`.
5. `"http://{}:{}".format(host, port)` — вставляем хост и порт в шаблон и получаем адрес вида `http://силенок.рф:8000`.

**Что делаем.** Сохраняем адрес сервера в переменную `BASE` и проверяем, что программа запускается.
