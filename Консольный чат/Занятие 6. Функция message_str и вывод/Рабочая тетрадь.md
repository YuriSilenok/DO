### Шаг 2. Функция message_str: словарь сообщения → строка

**Что делаем.** Пишем функцию `message_str(message)`, возвращающую красивую строку.

**Как это работает.** Внутри сообщения три ключа: `id`, `username`, `text`. Мы аккуратно достаём их через `.get(...)` с значениями по умолчанию — так функция не упадёт, даже если сервер пришлёт словарь без какого-то ключа.

**Пишем.** После `poll` набираем:

```python
def message_str(message):
    username = message.get("username", "?")
    text = message.get("text", "")
    return "{}: {}".format(username, text)
```

**Как это работает.**

1. `message.get("username", "?")` — если автор не указан, подставим `?`.
2. `message.get("text", "")` — если текста нет, подставим пустую строку и покажем просто «имя:».
3. `"{}: {}".format(username, text)` — формат «имя: текст».

Обратите внимание: `id` мы **не используем** для вывода — автор и текст важнее. Но в структуре сообщения `id` остаётся и пригодится, например, для отслеживания `last`.

```
python -c "import chat; print(chat.message_str({'username': 'Вася', 'text': 'Привет!'}))"
```
