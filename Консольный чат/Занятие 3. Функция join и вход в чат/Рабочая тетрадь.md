# Часть 1. Классная работа

### Шаг 1. Логин из переменной окружения

**Что делаем.** Придумываем себе имя в чате и учимся передавать его через переменную окружения.

**Как это работает.** В чате каждый участник должен иметь имя — сервер иначе не сможет понять, кто пишет. Хранить имя прямо в коде неудобно: пришлось бы переписывать файл ради смены ника. Поэтому, как и адрес сервера в занятии 1, возьмём имя из переменной окружения `CHAT_USERNAME`, а по умолчанию — `"Пользователь"`.

**Пишем.** В начало функции `join`, которую мы вот-вот напишем, добавится чтение логина:

```python
def join():
    params = {"username": os.getenv("CHAT_USERNAME", "Пользователь")}
    response = post("join", params)
    ...
```

**Как это работает.**

1. `os.getenv("CHAT_USERNAME", "Пользователь")` — читаем имя из переменной окружения или берём имя по умолчанию.
2. `params` — это **отдельный** словарь с именем: он уйдёт в функцию `post`, а та уже добавит `action` и `data`.

### Шаг 2. Функция join: отправляем запрос и разбираем ответ

**Что делаем.** Пишем функцию `join` целиком.

**Как это работает.** Функция должна сделать три дела:

1. Собрать `params` с именем пользователя.
2. Отправить запрос `post("join", params)`.
3. Разобрать ответ: напечатать сообщение об успехе или об ошибке. А ещё в ответе сервера есть поле `last` — номер последнего сообщения. Сейчас мы в него просто заглянем, а пользоваться по-настоящему будем на занятии 8.

Вспомним формат ответа сервера: это словарь с ключом `ok` (истина/ложь). Если `ok` истинный — приветствие, если нет — ошибка из ключа `error`.

**Пишем.** После `post` набираем:

```python
def join():
    params = {"username": os.getenv("CHAT_USERNAME", "Пользователь")}
    response = post("join", params)
    if not response or not response.get("ok"):
        print("Не удалось войти в чат")
        return None, None
    print("Добро пожаловать,", response.get("text", "Пользователь"))
    last = response.get("last", 0)
    print("Последнее сообщение:", last)
    return params["username"], last
```

**Как это работает.**

1. `if not response` — пришёл `None` от `post` (сеть/таймаут): выходим.
2. `not response.get("ok")` — сервер честно сказал «не пущу».
3. `return None, None` — показываем, что войти не получилось.
4. `response.get("text", "Пользователь")` — текст приветствия от сервера.
5. `last = response.get("last", 0)` — номер последнего сообщения (по умолчанию 0).
6. `return params["username"], last` — возвращаем имя и номер последнего, они пригодятся на следующих занятиях.

### Шаг 3. Что возвращает join и куда это пригодится

**Что делаем.** Разбираемся, зачем `join` возвращает `(username, last)`.

**Как это работает.** Вернув из функции сразу два значения, мы в одном месте получаем и имя, под которым вошли, и точку отсчёта сообщений. На занятии 8 эти два значения «склеятся» в цикле `main`: пока `join` не вернёт их, программа не начнёт спрашивать сообщения.
