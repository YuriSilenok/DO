# Часть 1. Классная работа

### Шаг 1. Что такое JSON и зачем ему Content-Type

**Что делаем.** Разбираемся с форматом, в котором клиент и сервер обмениваются данными.

**Как это работает.** Когда мы отправляем серверу данные, они должны быть в особом виде — **JSON**. Это текст, очень похожий на словари Python. Например:

```json
{"username": "Вася", "action": "join"}
```

Сервер не знает Python, поэтому имена полей пишутся в **двойных кавычках**, а булевы значения — `true` / `false` (с маленькой буквы). За превращение «словарь Python → JSON-строка» отвечает модуль `json`.

Кроме самих данных, важно сказать серверу, **чем** мы отправили тело запроса. Для этого существует заголовок `Content-Type: application/json`. Без него сервер может не понять, где заканчиваются данные.

**Проверь себя.** Откройте интерактивный режим Python и выполните:

```
python -c "import json; print(json.dumps({'username': 'Вася', 'action': 'join'}))"
```

На экране появится JSON-строка — смотрите внимательно: кавычки двойные.

### Шаг 2. Собираем запрос в словарь и читаем ответ

**Что делаем.** Пишем основу функции `post`.

**Как это работает.** Функция получает два словаря — `params` (параметры внутри запроса) и `data` (полезные данные). Всю работу проще всего разбить на три действия:

1. **Собрать тело запроса.** Добавляем обязательный ключ `action` к `data` — сервер должен понимать, *что* мы хотим сделать. Затем `json.dumps` превращает словарь в строку, а `.encode("utf-8")` — в байты (именно байты умеет отправлять `urllib`).
2. **Создать запрос.** Объект `urllib.request.Request` хранит адрес, метод `"POST"`, тело и заголовки.
3. **Отправить и прочитать.** `urlopen` выполняет запрос и возвращает ответ; у ответа читаем тело `.read()` и превращаем его из JSON обратно в словарь.

**Ответ сервера** — это тоже JSON-объект. У него есть ключ `ok`, который говорит, успешно ли прошла операция, и необязательные ключи с результатом (`text`, `messages`, `error` и т. д.).

**Пишем.** После `BASE = base_url()` набираем:

```python
def post(path, params=None, data=None):
    data = {} if data is None else data
    data["action"] = path
    body = json.dumps(data).encode("utf-8")
    headers = {"Content-Type": "application/json"}
    request = urllib.request.Request(
        "{}/{}".format(BASE, path),
        data=body,
        headers=headers,
        method="POST",
    )
    try:
        response = urllib.request.urlopen(request, timeout=3)
    except Exception:
        return None
    return response.read().decode("utf-8")
```

**Как это работает.**

1. `data = {} if data is None else data` — если данные не передали, работаем с пустым словарём.
2. `data["action"] = path` — прямо в словарь кладём, что мы хотим сделать (`join`, `send`, `poll`…).
3. `body = json.dumps(data).encode("utf-8")` — словарь → JSON-строка → байты. Ключевой момент для JSON-запросов!
4. `headers = {"Content-Type": "application/json"}` — сообщаем серверу, что отправляем JSON.
5. `"{}/{}".format(BASE, path)` — склеиваем адрес сервера и путь действия, например `http://силенок.рф:8000/join`.
6. `urlopen(request, timeout=3)` — отправляем запрос и ждём ответ максимум 3 секунды.
7. `except Exception: return None` — при любой ошибке (сервер не ответил, сеть упала) возвращаем `None`. Ошибки разберём на следующем шаге.
8. `response.read().decode("utf-8")` — читаем тело ответа и превращаем байты в текст.

**Проверь себя.** Запустите `python chat.py` — ошибок быть не должно (функция определилась, но мы её пока не вызывали).

### Шаг 3. Кладём JSON-ответ в `json.loads` и боремся с ошибками

**Что делаем.** Учимся аккуратно разбирать ответ сервера.

**Как это работает.** Текст ответа — это строка. Чтобы работать с ней как со словарём, превращаем её в словарь: `json.loads(text)`. Но договориться с сервером может не получиться: он может ответить не-JSON, вообще не ответить (тогда у нас `None`) или вернуть статус ошибки. Поэтому правильный код всегда защищает себя от таких сюрпризов.

**Пишем.** В конце функции `post` заменяем строку с `return response.read().decode("utf-8")` на аккуратный разбор:

```python
    try:
        response = urllib.request.urlopen(request, timeout=3)
    except Exception:
        return None
    try:
        text = response.read().decode("utf-8")
        return json.loads(text)
    except Exception:
        return None
```

**Как это работает.**

- Внешний `try` ловит ошибки **отправки** — сеть недоступна, таймаут, сервер не принял соединение.
- Внутренний `try` ловит ошибки **разбора ответа** — пришло не-JSON, обрезанный ответ, пустая строка.
- В обоих случаях возвращаем `None`. Безопасное правило: если не получилось понять сервер — лучше вернуть `None`, чем уронить всю программу.

### Шаг 4. Функция post целиком — сравниваем с образцом

**Что делаем.** Собираем полный текст функции и сверяем его с образцом.

**Как это работает.** После занятия 1 в вашем файле импорты, `base_url` и `BASE`. Сразу после них должна стоять функция `post`. Полностью она выглядит так:

```python
def post(path, params=None, data=None):
    data = {} if data is None else data
    data["action"] = path
    body = json.dumps(data).encode("utf-8")
    headers = {"Content-Type": "application/json"}
    request = urllib.request.Request(
        "{}/{}".format(BASE, path),
        data=body,
        headers=headers,
        method="POST",
    )
    try:
        response = urllib.request.urlopen(request, timeout=3)
    except Exception:
        return None
    try:
        text = response.read().decode("utf-8")
        return json.loads(text)
    except Exception:
        return None
```

**Проверь себя.** Сравните с образцом: в реальном `chat.py` функция `post` занимает **строки 31–44**. Ваша версия должна получиться такой же по порядку: собрать тело, заголовки, отправить, разобрать ответ, при ошибке — `None`.
