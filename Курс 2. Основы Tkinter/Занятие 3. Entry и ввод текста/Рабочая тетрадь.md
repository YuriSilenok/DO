# Рабочая тетрадь. Занятие 3. Entry и ввод текста

## Цель занятия
Научиться получать текст от пользователя через поле ввода.

## Шаг 1. Поле ввода
```python
import tkinter as tk

root = tk.Tk()
root.title('Поле ввода')
root.geometry('300x200')

entry = tk.Entry(root)
entry.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Поле ввода')` — задаёт заголовок окна.
- `root.geometry('300x200')` — задаёт размеры окна в пикселях.
- `entry = tk.Entry(root)` — создаёт однострочное поле для ввода текста.
- `entry.pack()` — размещает поле ввода в окне.
- `root.mainloop()` — запускает цикл событий окна.

## Шаг 2. Кнопка для чтения текста

```python
import tkinter as tk

entry = tk.Entry(root)
entry.pack()

button = tk.Button(root, text='Поприветствовать')
button.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Приветствие')` — задаёт заголовок окна.
- `root.geometry('300x200')` — задаёт размеры окна в пикселях.
- `label = tk.Label(root, text='Введите имя:')` — создаёт надпись с инструкцией.
- `label.pack()` — размещает надпись в окне.
- `entry = tk.Entry(root)` — создаёт поле, куда пользователь введёт имя.
- `entry.pack()` — размещает поле ввода в окне.
- `button = tk.Button(root, text='Поприветствовать')` — создаёт кнопку с указанным текстом.

- `root.mainloop()` — запускает цикл событий окна.

## Добавляем действие по кнопке
```python
import tkinter as tk

root = tk.Tk()
root.title('Приветствие')
root.geometry('300x200')

label = tk.Label(root, text='Введите имя:')
label.pack()

entry = tk.Entry(root)
entry.pack()

result = tk.Label(root, text='')
result.pack()

def say_hello():
    name = entry.get()
    result.config(text=f'Привет, {name}!')

button = tk.Button(root, text='Поприветствовать', command=say_hello)
button.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Приветствие')` — задаёт заголовок окна.
- `root.geometry('300x200')` — задаёт размеры окна в пикселях.
- `label = tk.Label(root, text='Введите имя:')` — создаёт надпись с инструкцией.
- `label.pack()` — размещает надпись в окне.
- `entry = tk.Entry(root)` — создаёт поле для ввода имени.
- `entry.pack()` — размещает поле ввода в окне.
- `result = tk.Label(root, text='')` — создаёт пустую надпись, в которой позже появится результат.
- `result.pack()` — размещает надпись для результата в окне.
- `def say_hello():` — объявляет функцию, которая выполнится при нажатии кнопки.
- `name = entry.get()` — получает текст из поля ввода и сохраняет его в `name`.
- `result.config(text=f'Привет, {name}!')` — меняет текст надписи на приветствие с введённым именем.
- `button = tk.Button(root, text='Поприветствовать', command=say_hello)` — создаёт кнопку и связывает её с функцией `say_hello`.
- `button.pack()` — размещает кнопку в окне.
- `root.mainloop()` — запускает цикл событий окна.
