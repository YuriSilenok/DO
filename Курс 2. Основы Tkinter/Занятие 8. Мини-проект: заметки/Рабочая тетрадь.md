## Цель занятия
Объединить знания Tkinter в маленькое приложение.

## Что будет делать программа
- добавлять заметку;
- показывать список заметок;
- удалять заметку;
- очищать список.

## Ключевой код
```python
import tkinter as tk

root = tk.Tk()
root.title('Заметки')
root.geometry('350x350')

entry = tk.Entry(root, width=30)
entry.pack()

listbox = tk.Listbox(root, width=30, height=12)
listbox.pack()

def add_note():
    note = entry.get()
    if note:
        listbox.insert(tk.END, note)
        entry.delete(0, tk.END)

def delete_note():
    selected = listbox.curselection()
    if selected:
        listbox.delete(selected[0])

def clear_notes():
    listbox.delete(0, tk.END)

add_button = tk.Button(root, text='Добавить', command=add_note)
add_button.pack()

delete_button = tk.Button(root, text='Удалить', command=delete_note)
delete_button.pack()

clear_button = tk.Button(root, text='Очистить', command=clear_notes)
clear_button.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Заметки')` — задаёт заголовок окна.
- `root.geometry('350x350')` — задаёт размеры окна в пикселях.
- `entry = tk.Entry(root, width=30)` — создаёт поле шириной 30 символов для ввода заметки.
- `entry.pack()` — размещает поле ввода в окне.
- `listbox = tk.Listbox(root, width=30, height=12)` — создаёт список заметок шириной 30 символов и высотой 12 строк.
- `listbox.pack()` — размещает список в окне.
- `def add_note():` — объявляет функцию добавления заметки.
- `note = entry.get()` — получает текст заметки из поля ввода.
- `if note:` — проверяет, что поле ввода не пустое.
- `listbox.insert(tk.END, note)` — добавляет заметку в конец списка.
- `entry.delete(0, tk.END)` — очищает поле ввода после добавления заметки.
- `def delete_note():` — объявляет функцию удаления заметки.
- `selected = listbox.curselection()` — получает индекс выбранной заметки.
- `if selected:` — проверяет, что заметка выбрана.
- `listbox.delete(selected[0])` — удаляет выбранную заметку из списка.
- `def clear_notes():` — объявляет функцию очистки списка заметок.
- `listbox.delete(0, tk.END)` — удаляет все элементы, от первого до последнего.
- `add_button = tk.Button(root, text='Добавить', command=add_note)` — создаёт кнопку добавления и связывает её с функцией `add_note`.
- `add_button.pack()` — размещает кнопку добавления в окне.
- `delete_button = tk.Button(root, text='Удалить', command=delete_note)` — создаёт кнопку удаления и связывает её с функцией `delete_note`.
- `delete_button.pack()` — размещает кнопку удаления в окне.
- `clear_button = tk.Button(root, text='Очистить', command=clear_notes)` — создаёт кнопку очистки и связывает её с функцией `clear_notes`.
- `clear_button.pack()` — размещает кнопку очистки в окне.
- `root.mainloop()` — запускает цикл событий окна.
