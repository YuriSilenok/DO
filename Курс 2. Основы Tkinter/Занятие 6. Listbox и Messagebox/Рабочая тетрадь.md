# Рабочая тетрадь. Занятие 6. Listbox и Messagebox

## Цель занятия
Научиться выводить список элементов и показывать диалоговые окна.

## Шаг 1. Listbox
```python
import tkinter as tk

root = tk.Tk()
root.title('Список')
root.geometry('300x220')

listbox = tk.Listbox(root)
for item in ['Python', 'Java', 'C++', 'JavaScript']:
    listbox.insert(tk.END, item)
listbox.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Список')` — задаёт заголовок окна.
- `root.geometry('300x220')` — задаёт размеры окна в пикселях.
- `listbox = tk.Listbox(root)` — создаёт список, в котором пользователь сможет выбирать элементы.
- `for item in ['Python', 'Java', 'C++', 'JavaScript']:` — по очереди перебирает названия языков программирования.
- `listbox.insert(tk.END, item)` — добавляет текущий язык в конец списка.
- `listbox.pack()` — размещает список в окне.
- `root.mainloop()` — запускает цикл событий окна.

## Шаг 2. Messagebox
```python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title('Диалог')
root.geometry('300x150')

def show_message():
    messagebox.showinfo('Информация', 'Привет из Tkinter!')

button = tk.Button(root, text='Показать сообщение', command=show_message)
button.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `from tkinter import messagebox` — подключает готовые диалоговые окна Tkinter.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Диалог')` — задаёт заголовок окна.
- `root.geometry('300x150')` — задаёт размеры окна в пикселях.
- `def show_message():` — объявляет функцию, которая покажет диалоговое окно.
- `messagebox.showinfo('Информация', 'Привет из Tkinter!')` — показывает информационное сообщение с заголовком и текстом.
- `button = tk.Button(root, text='Показать сообщение', command=show_message)` — создаёт кнопку и связывает её с функцией показа сообщения.
- `button.pack()` — размещает кнопку в окне.
- `root.mainloop()` — запускает цикл событий окна.
