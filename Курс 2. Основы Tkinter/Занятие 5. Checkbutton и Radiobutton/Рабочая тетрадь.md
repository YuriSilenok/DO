## Цель занятия
Научиться использовать флажки и переключатели.

## Шаг 1. Checkbutton
```python
import tkinter as tk

root = tk.Tk()
root.title('Флажки')
root.geometry('300x180')

check = tk.BooleanVar()
checkbox = tk.Checkbutton(root, text='Согласен', variable=check)
checkbox.pack()

label = tk.Label(root, text='Статус: не выбран')
label.pack()

def update_status():
    if check.get():
        label.config(text='Статус: выбран')
    else:
        label.config(text='Статус: не выбран')

checkbox.config(command=update_status)
root.mainloop()
```

**Пояснения к новым строкам:**
- `check = tk.BooleanVar()` — создаёт переменную Tkinter для хранения значения `True` или `False`.
- `checkbox = tk.Checkbutton(root, text='Согласен', variable=check)` — создаёт флажок, связанный с переменной `check`.
- `def update_status():` — объявляет функцию для обновления статуса.
- `if check.get():` — проверяет, установлен ли флажок.
- `else:` — задаёт действие для случая, когда условие выше не выполнено.

## Шаг 2. Radiobutton
```python
import tkinter as tk

root = tk.Tk()
root.title('Выбор цвета')
root.geometry('300x180')

choice = tk.StringVar(value='Красный')

colors = ['Красный', 'Зелёный', 'Синий']
for color in colors:
    tk.Radiobutton(root, text=color, variable=choice, value=color).pack()

label = tk.Label(root, text='Выбран: Красный')
label.pack()

def show_choice():
    label.config(text='Выбран: ' + choice.get())

button = tk.Button(root, text='Показать выбор', command=show_choice)
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `choice = tk.StringVar(value='Красный')` — создаёт переменную для текста выбранного варианта и задаёт начальный выбор.
- `colors = ['Красный', 'Зелёный', 'Синий']` — создаёт список доступных цветов.
- `for color in colors:` — по очереди перебирает каждый цвет из списка.
- `def show_choice():` — объявляет функцию для отображения выбранного значения.
