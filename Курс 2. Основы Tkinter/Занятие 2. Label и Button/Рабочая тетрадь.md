# Рабочая тетрадь. Занятие 2. Label и Button

## Цель занятия
Научиться добавлять текст и кнопки на форму.

## Шаг 1. Создаём надпись
```python
import tkinter as tk

root = tk.Tk()
root.title('Label')
root.geometry('300x150')

label = tk.Label(root, text='Привет, мир!')
label.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `label = tk.Label(root, text='Привет, мир!')` — создаёт текстовую надпись внутри окна.
- `label.pack()` — размещает надпись в окне.

## Шаг 2. Добавляем кнопку
```python
import tkinter as tk

root = tk.Tk()
root.title('Кнопка')
root.geometry('250x150')

label = tk.Label(root, text='Нажми кнопку')
label.pack()

button = tk.Button(root, text='Нажать')
button.pack()

root.mainloop()
```

**Пояснения к новым строкам:**
- `button = tk.Button(root, text='Нажать')` — создаёт кнопку с текстом «Нажать».
