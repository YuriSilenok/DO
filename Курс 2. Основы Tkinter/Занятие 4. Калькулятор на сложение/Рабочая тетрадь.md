# Рабочая тетрадь. Занятие 4. Калькулятор на сложение

## Цель занятия
Сделать простую программу для сложения двух чисел.

## Шаг 1. Создаём поля и кнопку
```python
import tkinter as tk

root = tk.Tk()
root.title('Калькулятор')
root.geometry('300x220')

label1 = tk.Label(root, text='Число 1:')
label1.pack()
entry1 = tk.Entry(root)
entry1.pack()

label2 = tk.Label(root, text='Число 2:')
label2.pack()
entry2 = tk.Entry(root)
entry2.pack()

result = tk.Label(root, text='Результат: ')
result.pack()

def add_numbers():
    a = int(entry1.get())
    b = int(entry2.get())
    total = a + b
    result.config(text=f'Результат: {total}')

button = tk.Button(root, text='Сложить', command=add_numbers)
button.pack()

root.mainloop()
```

**Пояснение к каждой строке:**
- `import tkinter as tk` — подключает Tkinter под коротким именем `tk`.
- `root = tk.Tk()` — создаёт главное окно.
- `root.title('Калькулятор')` — задаёт заголовок окна.
- `root.geometry('300x220')` — задаёт размеры окна в пикселях.
- `label1 = tk.Label(root, text='Число 1:')` — создаёт подпись для первого числа.
- `label1.pack()` — размещает подпись в окне.
- `entry1 = tk.Entry(root)` — создаёт поле ввода первого числа.
- `entry1.pack()` — размещает первое поле ввода.
- `label2 = tk.Label(root, text='Число 2:')` — создаёт подпись для второго числа.
- `label2.pack()` — размещает подпись в окне.
- `entry2 = tk.Entry(root)` — создаёт поле ввода второго числа.
- `entry2.pack()` — размещает второе поле ввода.
- `result = tk.Label(root, text='Результат: ')` — создаёт надпись, в которой будет показан результат.
- `result.pack()` — размещает надпись результата в окне.
- `def add_numbers():` — объявляет функцию для сложения чисел.
- `a = int(entry1.get())` — получает текст из первого поля и преобразует его в целое число.
- `b = int(entry2.get())` — получает текст из второго поля и преобразует его в целое число.
- `total = a + b` — складывает два числа и сохраняет сумму.
- `result.config(text=f'Результат: {total}')` — показывает сумму в надписи результата.
- `button = tk.Button(root, text='Сложить', command=add_numbers)` — создаёт кнопку и назначает ей функцию сложения.
- `button.pack()` — размещает кнопку в окне.
- `root.mainloop()` — запускает цикл событий окна.
